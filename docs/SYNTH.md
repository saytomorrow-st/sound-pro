# Полифонический синтезатор (SPEC-009)

`audio_core::synth` превращает события `Schedule` в звук: две связанные части —
**голос** (осциллятор + огибающая) и **`Synth`** (пул голосов, выделение и
вытеснение). Модуль чистый: без I/O, без `unsafe`, без аллокаций на горячем
пути.

## Ноты → частота

Равномерная темперация, A4 = 440 Гц:

```text
freq(note) = 440 * 2^((note - 69) / 12)
```

`pub fn note_to_hz(note: u8) -> f64` — `69 → 440`, `57 → 220`, `81 → 880`,
`60 → 261.6255…`. Частота считается **один раз** в момент `NoteOn` и дальше
лежит в голосе: на горячем пути нет ни `powf`, ни таблиц.

## Огибающая

Четыре стадии, все длительности в секундах переводятся в сэмплы при старте
голоса (`sample_rate` приходит в конструктор `Synth`):

| стадия | поведение |
|---|---|
| attack | линейный рост `0 → peak` за `attack_s` |
| decay | линейный спад `peak → peak * sustain` за `decay_s` |
| sustain | ровно `peak * sustain` |
| release | линейный спад от текущего уровня до `0` за `release_s` |

Значения по умолчанию: `attack_s = 0.005`, `decay_s = 0.08`, `sustain = 0.7`,
`release_s = 0.12`. При `48 кГц` это 240, 3840 и 5760 сэмплов.

Пик голоса — `velocity / 127` (`SPEC-009`, п. 6): velocity 100 даёт `0.7874`,
velocity 127 — `1.0`. Голоса **суммируются** без нормализации; 16 нот по
`1.0` дают `16.0` — клиппинг оставлен следующему узлу.

Про `release`: голос запоминает **уровень в момент `NoteOff`** (`level_at` по
абсолютному сэмплу), а не уровень конца прошлого кванта. Иначе длительность
release зависела бы от размера кванта — это и был реальный баг, найденный
тестом на независимость от кванта.

## Фаза осциллятора

```text
phase(t) = TAU * freq * (t - started_at) / sample_rate
value(t) = sin(phase + TAU / 4) * gain(t)      // cos(phase) * gain(t)
```

Косинусная фаза (сдвиг на `TAU/4`) нужна, чтобы нота была слышна на **первом**
же сэмпле, а не начиналась с нулевого перехода синуса. Фаза считается от
абсолютного сэмпла, поэтому квантование кванта (256 vs 8192) не меняет звук:
оба рендера совпадают бит-в-бит.

Следствие, важное для тестов: мгновенное значение осциллятора может быть выше
огибающей в момент, когда гребень волны попадает на спад decay. Инвариант
«ни один сэмпл не превышает пик огибающей» **неверен**; измерять огибающую
надо по гребням (окрестность сэмпла), а не по одному значению.

## Голоса и вытеснение

- `MAX_VOICES = 16`.
- `NoteOn` ищет свободный голос (`peak == 0` или уже погасший).
- Свободных нет — вытесняется голос с наименьшим текущим `gain` (слышимо
  тишайший), при равенстве — самый ранний по индексу, а он же самый старый,
  потому что занятие всегда берёт первый свободный.
- `NoteOn` для уже звучащей пары `(channel, note)` **перезапускает** голос
  (сброс фазы и огибающей), а не добавляет второй: иначе двойной `NoteOn`
  удваивал бы громкость.
- `NoteOff` переводит **все** голоса с этой парой в release; `NoteOff` без
  `NoteOn` игнорируется.
- Голос освобождается (обнуляется), когда release доигран и `gain == 0`.

## API

```rust
use audio_core::synth::{Envelope, Synth};

let mut synth = Synth::new(48_000, Envelope::default())?;  // 0 Гц → SynthError
synth.render(&schedule, &mut cursor, position, frames, &mut out);  // моно, out[..frames]
synth.reset();                                            // погасить все голоса
synth.voices_started();                                   // счётчик NoteOn
```

`reset` и перемотка курсора — обязанность узла: `daw_app::nodes::PolySynth`
делает это при `ctx.position < last_position` (seek назад). Само по себе
перемещение курсора, без `reset`, оставило бы звучащие голоса висеть.

## Периферия

- Узел `daw_app::nodes::PolySynth`: `Synth` + `Schedule` + `ScheduleCursor` +
  `last_position`, выход в канал 0, живой параметр `synth.gain` (0..1, по
  умолчанию 0.5, рампа 10 мс).
- CLI: `daw render-midi <in.mid> <out.wav> [--tempo BPM] [--seconds S]` —
  парсит SMF, строит `ScheduleSpec::from_midi(..., tail_samples = SR)`,
  рендерит в WAV и печатает число сэмплов, нот и стартовавших голосов.

```bash
cargo run -q --bin daw -- render-midi /tmp/tune.mid /tmp/tune.wav
# rendered 132000 frames (schedule 132000), 3 notes, 3 voice starts
```

## Вне области

Фильтры, LFO, эффекты, сэмплер, автоматизация, pitch bend и poly pressure,
антиалиасинг и передискретизация. Все MIDI-каналы звучат одним тембром.
