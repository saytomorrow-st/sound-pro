# Дорожная карта Sound Pro

Здесь — «что дальше и в каком порядке». Полный список закрытых спецификаций
(001–074) описан в `docs/PROJECT_STATE.md` и `specs/`.

Каждая строка — отдельный PR и отдельный релиз. Одна задача за раз.

## Сейчас: RFC-002 (стриминг сэмплов) — этапы 0–7 влиты

RFC-001 (сэмплер/SFZ) реализован по PR 1–7: парсер SFZ, движок голосов,
загрузка банка, выбор инструмента, библиотека банков, скачивание банков, а
также шаг A SPEC-068 (опция 4-точечной интерполяции Эрмита, по умолчанию
Linear). Шаг B SPEC-068 закрыт как RFC-002: PCM-кэш банка, целостность L0–L3,
`load_bank_auto`, стриминг (`VoiceStream`/`StreamLoader`), фикс SFZ `vl2` (#109)
и тесты эквивалентности/стресс (#110, спеки 069–074) — этапы 0–7 влиты по
PR #103–#110. Полное описание — в `docs/rfc/002-sample-streaming.md` и разделе
«RFC-002» в `docs/PROJECT_STATE.md`. Осталось: релиз/тег и отложенное по
RFC-002 — см. «Отложено».

## Отложено

- **RFC-002 — релиз/тег** не сделан: этапы 0–7 влиты в `main`, но версия/тег и
  релиз — отдельный PR владельца (в этой задаче код не менялся и версия не
  повышалась).
- **RFC-002 — GUI-прогресс построения кэша для старых банков.** Фоновое
  построение PCM-кэша для банков без `cache/` сейчас отчитывается только в лог;
  показ прогресса в UI отложен.
- **RFC-002 — известные отклонения от RFC** (см. `docs/rfc/002-sample-streaming.md`):
  HEAD при загрузке банка 32768 фреймов вместо номинальных 65536; запросы
  loader-а в FIFO без сортировки по дедлайну; бенчмарки латентности не
  проводились; `SyncStream` реализован как синхронный `pump` (offline-путь), а
  не фоновый поток.
- Перетаскивание окна за полосу (SPEC-050 §1): у окна нет панели, за которую
  его тянуть. Кнопки окна в фуллскрине работают (v0.1.34). Вернуться, если
  владелец попросит.

## Ближайший горизонт

- Живая проверка владельцем SPEC-051 — SPEC-074 (микшер с шинами и посылами,
  экспорт с нормализацией, импорт FLAC/OGG, темпо-полоса, папки дорожек,
  MIDI-редактирование, сэмплер, библиотека банков и стриминг).
- Релиз/тег RFC-002 (этапы 0–7 уже в `main`).
- Плагинная модель: эффекты как отдельные динамические модули.
- Собственный DnD для Wayland (сейчас приложение идёт через XWayland).

## Средний горизонт

- Библиотека лупов на собственных сэмплах.
- Анализ громкости LUFS и автосведение.
- Доводка RFC-002: GUI-прогресс построения кэша, сортировка запросов по
  дедлайну, бенчмарки латентности (если банк превысит бюджет RAM или появится
  реальная нагрузка на стриминг).

## Правила движения

1. Одна задача — один PR — один тег.
2. Без спецификации код не пишется: сначала `specs/NNN-*.md` с критериями
   приёмки и граничными случаями.
3. Тесты пишутся до реализации; golden-файлы не трогаются.
4. Фича готова только после ручной проверки пользователем. Отчёт агента без
   живой проверки — гипотеза, а не результат.
5. Регрессия важнее новой функции: баг от пользователя идёт вперёд очереди.

## Не входит в план

- `unsafe` в движке и оболочке.
- Платформенные API в `audio-core`.
- Изменение golden-эталонов агентом.
