# Дорожная карта: рабочий прототип

Цель — программа с окном для Linux и Windows, в которой можно собрать трек
из аудиофайлов, послушать, сведить и сохранить. Всё пишется по методу чистой
комнаты: только по нашим спецификациям, без чужого кода и ресурсов.

Каждая строка — отдельная спецификация `specs/NNN-*.md` и отдельный PR.

| # | Задача | Что увидит пользователь | Статус |
|---|---|---|---|
| 015 | Окно приложения (`daw-gui`) | Окно: дорожки и клипы на таймлайне, микшер, открыть/сохранить проект, импорт WAV, экспорт сведения | готово |
| 016 | Воспроизведение в окне | Кнопки Play/Stop, бегущий курсор, звук из колонок | готово |
| 017 | Редактирование клипов мышью | Перетаскивание, обрезка краёв, удаление, сетка тактов | готово |
| 018 | Отмена/повтор | Ctrl+Z / Ctrl+Shift+Z для всех правок | готово |
| 019 | Ресемплинг при импорте | WAV любой частоты импортируется | готово |
| 020 | Запись с микрофона | Кнопка Record на дорожке | готово |
| 021 | MIDI-дорожки и piano roll | Ноты рисуются мышью, играет встроенный синтезатор | готово |
| 022 | Эффекты на дорожках | EQ, компрессор, реверб в слотах микшера | готово |
| 023 | Автоматизация | Линии громкости и панорамы на дорожках | готово |
| 024 | Сборки для пользователей | Готовые файлы для Linux (AppImage) и Windows (.exe) в релизах GitHub | готово |
