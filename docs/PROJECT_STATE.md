# Состояние проекта Sound Pro

Снимок на 2026-10-31. Последний релиз — **v0.1.28** (`ad79abd`, merge PR #59).

## Текущее состояние

- Открытая DAW на Rust для Linux и Windows, пишется по методу чистой комнаты
  (только свои спецификации, без чужого кода).
- Спецификации 001–049 закрыты и выпущены; SPEC-050 (окно, дроп, стерео/моно,
  быстрый MP3) выполнена частично.
- Объём: ~24 тыс. строк Rust в трёх крейтах. Все 49 спецификаций, кроме
  текущей, имеют полный набор тестов; гейт `fmt`/`clippy -D warnings`/`test`
  зелёный на `main`.
- Сборки: AppImage (Linux) и zip (Windows) в GitHub Releases, версия берётся из
  тега (в `Cargo.toml` остаётся `0.1.0`).

## Архитектура

Три крейта, строго по слоям (подробнее — `docs/ARCHITECTURE.md`):

```
crates/audio-core   движок, #![forbid(unsafe_code)], без платформенных API
crates/daw-app      оболочка: файлы, кэш, метры, бэкенды (CPAL за фичей realtime)
crates/daw-gui      окно на eframe/egui: таймлайн, микшер, инспектор
```

Правило реального времени: код в `Graph::process`, `Renderer::render` и
аудиоколбэке не аллоцирует, не блокирует и не делает I/O; обмен с UI — через
`rtrb`.

## Известные баги

| # | Симптом | Причина / состояние |
|---|---|---|
| 1 | При перетаскивании файла регион встаёт не под курсором (зависит от размера экрана), а не туда, куда указывает мышь | Патчи #57–#59 чинили логику поверх позиции указателя, но не саму позицию: winit 0.30.13 на X11 не шлёт `CursorMoved` во время внешнего XDND-драга. Дроп: позиция из `XQueryPointer` (`win_x`/`win_y`) — так вставка работала в PR #62 (итерация 2); PR #63 сломал её латчем со сбросом по маске кнопок, латч убран. Призрак: под XWayland при Wayland-источнике `XQueryPointer` во время драга заморожен, поэтому в вендоренном winit (`vendor/winit`, 0.30.13 + патч) `XdndPosition` превращается в `CursorMoved`. **Не проверено владельцем вживую.** |
| 2 | Дроп на существующую дорожку с регионами всегда создаёт новую | Следствие #1: без верной позиции hit-test дорожки промахивается. Чинится вместе с #1; не проверено вживую. |
| 3 | В полноэкранном режиме нет управления окном | SPEC-050 §1 не реализована. |
| 4 | Приложение на Wayland идёт через XWayland | eframe включён без фичи `wayland`: winit 0.30.13 не умеет DnD на Wayland. Включать нельзя, пока не будет своя реализация. |

## Используемые технологии

- Rust 2024 edition, toolchain 1.85, workspace из трёх крейтов.
- `eframe`/`egui` 0.33 (glow + x11), `rfd` для диалогов файлов.
- `cpal` 0.15 (опционально, фича `realtime`): WASAPI на Windows, ALSA/PipeWire
  на Linux.
- `symphonia` 0.5 — декодирование MP3; `hound` — WAV; `rtrb` — SPSC-очереди;
  `thiserror` — ошибки.
- Без `serde`: проект хранится в текстовом JSON с разбором руками (SPEC-008).
- `cargo fmt`, `clippy -D warnings`, `cargo test`; GitHub Actions CI и Release.

## Важные решения по архитектуре

1. **Движок не знает про платформу.** `audio-core` не подключает аудиоустройств;
   всё, что трогает ОС, живёт в `daw-app`.
2. **Без `unsafe`.** `#![forbid(unsafe_code)]` в движке и оболочке.
3. **Реальный путь без аллокаций и блокировок.** Параметры сглаживаются,
   команды идут через `rtrb`, переполнение — не паника, а отбрасывание.
4. **Golden-тесты — оракул DSP.** `crates/audio-core/tests/golden/*.wav` не
   меняются агентом никогда; расхождение чинится в коде.
5. **Текстовый проект вместо бинарного.** Читаемость и диффы важнее размера.
6. **Офлайн-путь обязателен.** `selftest` и `bounce` работают без звуковой
   карты, поэтому тесты и агенты не зависят от оборудования.
7. **Версия из тега.** `Cargo.toml` не бампается, версия вычисляется из имени
   тега в `release.yml`.
8. **Разделение ролей агентов.** Координатор не пишет код; Opus-сессии
   реализуют; DeepSeek-сессии гоняют гейт и выпускают релизы.
