## Архитектура

Три крейта, строго по слоям (подробнее — `docs/ARCHITECTURE.md`):

```
crates/audio-core   движок, #![forbid(unsafe_code)], без платформенных API
crates/daw-app      оболочка: файлы, кэш, метры, бэкенды (CPAL за фичей realtime)
crates/daw-gui      окно на eframe/egui: таймлайн, микшер, инспектор
```

Правило реального времени: код в `Graph::process`, `Renderer::render` и
аудиоколбэке не аллоцирует, не блокирует и не делает I/O; обмен с UI — через
`rtrb`.

Вендорный winit: `vendor/winit` — это 0.30.13 плюс один патч (X11:
`XdndPosition` → `CursorMoved`), подключённый через `[patch.crates-io]`.
Описание и порядок обновления — `vendor/winit/SOUND_PRO_PATCH.md`: при переходе
eframe на новый winit копируем релиз из registry, переносим хунк (или убираем
вендор, если upstream сам шлёт `CursorMoved`), правим `[patch.crates-io]`,
делаем `cargo update -p winit` и прогоняем полный CI. Патч нельзя терять при
обновлении зависимостей.

`SamplerVoice` добавлен `Interpolation::{Linear, Hermite4}` с
`read_hermite_i16`/`read_hermite_stereo`; `SamplerEngine` умеет переключать
режим (`new_with`, `set_interpolation`). По умолчанию остаётся `Linear`, поэтому
выход бит-в-бит прежний и goldens не менялись. Тесты: ошибка синуса (Hermite не
хуже линейной на 10×), детерминизм по размерам блока, граничные случаи без
паники/NaN, отсутствие аллокаций в аудио-пути. Шаг B (потоковая подгрузка
сэмплов) реализован как **RFC-002** — см. раздел ниже.

## RFC-002: стриминг сэмплов и PCM-кэш (этапы 0–7, PR #103–#110)

Реализовано по `docs/rfc/002-sample-streaming.md` (этапы 0–7), спеки 069–074.
Это и есть «Шаг B» SPEC-068, оформленный отдельным RFC, когда условие запуска
наступило (Osiris в полном декоде превышает бюджет RAM). Всё влито в `main`,
но ещё не выпущено как релиз/тег.

**Этапы и спеки:**

| Этап | PR | Спека | Что вошло |
|---|---|---|---|
| 1 | #103 | 069 | Формат `.pcm` + `manifest.json`: reader/writer, атомарная запись, `SampleSource::Resident` без изменения поведения |
| 2 | #104 | — | Генерация PCM-кэша при `download_bank` (параллельно, без накопления банка) |
| 3 | #105 | 070 | Integrity L0–L3, карантин, автоперестроение из FLAC |
| 4 | #106 | 071 | `load_bank_from_cache`, `load_bank_auto`, бюджет RAM по `MemAvailable` |
| 5 | #107 | 072 | `VoiceStream`/`SampleHead`: голова в RAM, хвост через SPSC-кольца |
| 6 | #108 | 073 | `StreamLoader` (диск-поток) и интеграция Streaming в движок/банк |
| — | #109 | — | Фикс SFZ: сброс `<master>`/`<group>` scope на новом заголовке (тихий `vl2` в Osiris) |
| 7 | #110 | 074 | Эквивалентность Resident/Stream, стресс «педаль 128 голосов», `SyncStream` |

**Как банк выбирает Resident/Streaming.** Точка входа —
`sample_bank::load_bank_auto`. Бюджет = `min(DEFAULT_RAM_BUDGET_MIB,
MemAvailable − 256 МиБ)`, но не ниже пола 512 МиБ (`meminfo::effective_budget_mib`).
Сначала `load_bank_from_cache` читает весь кэш в RAM (Resident). Если
резидентные данные превышают бюджет (`RamBudgetExceeded`), банк грузится
повторно в Streaming: каждый **стерео**-сэмпл длиннее `STREAM_HEAD_FRAMES =
32_768` кадров держит в RAM только голову, хвост читается с диска; моно и
короткие сэмплы остаются Resident. При отсутствии кэша (банк от старой версии)
кэш строится в фоне, затем банк грузится из него; при неудаче — fallback на
декодирование FLAC.

**Структура кэша** — `~/.local/share/sound-pro/banks/<id>/cache/`
(`%LOCALAPPDATA%\sound-pro\banks\<id>\cache\` на Windows): по одному `.pcm` на
уникальный сэмпл (64-байтовый `SPCM`-заголовок + interleaved i16) и
`manifest.json` (атомарно, `.tmp` + `rename`) с хэшами и размерами. Кэш —
производные данные; удаление `cache/` безопасно, источник правды — FLAC.

**Уровни целостности** (при каждой загрузке инструмента): L0 (всегда, синхронно:
манифест, существование, размер, заголовок), L1 (всегда, фоном: mtime + sampled
xxh3-64), L2 (фоном, раз за сессию и после сбоя через `cache/.dirty`: полный
xxh3-128), L3 (по запросу/после сбоя: blake3 `.pcm` + xxh3-64 FLAC). Повреждённый
файл карантинится (`*.quarantined`) и пересобирается из FLAC; без исходника —
`unrecoverable` и предложение скачать банк заново.

**Замер Osiris (живая проверка владельца):** 3160 регионов, Streaming-режим,
загрузка 10–11 с, RSS ~166–168 МиБ (против ~2.6 ГиБ при полном декоде).

**Известные отклонения от RFC** (осознанные, не баги):
- **HEAD 32768 вместо 65536.** Номинал `audio-core::sampler::stream::HEAD_FRAMES
  = 65_536`, но фактическая голова банка задаётся
  `daw-app::sample_bank::STREAM_HEAD_FRAMES = 32_768` (≈0.68 с @48 кГц, ~155 МиБ
  голов на Osiris). RFC §7 рекомендовал 32 Ki по умолчанию — так и сделано.
- **Нет сортировки запросов по дедлайну.** `StreamLoader` обслуживает запросы
  в порядке поступления (FIFO `VecDeque`), а не по оставшемуся запасу кольца
  (RFC §4). Вынесено из SPEC-074 в «вне области».
- **Нет бенчмарков латентности.** RFC §7/§10 предполагал бенчмарки
  RSS/латентности; они не добавлены (SPEC-074 «вне области»).
- **`SyncStream` — синхронный `pump`.** Офлайн-рендер
  (`SamplerInstrument::render_notes`) прогоняет `StreamLoader::pump` перед
  каждым чанком, а не отдельный синхронный поток; результат бит-в-бит равен
  Resident (тест эквивалентности SPEC-074).

**Отложено:** GUI-прогресс фонового построения кэша для старых банков без
`cache/`. Сейчас `load_bank_auto` строит кэш в фоне и логирует прогресс
(`build_bank_cache` с callback в лог), но в UI прогресс не показывается;
fallback на декодирование FLAC при неудаче сохраняется.

**Код:** `crates/audio-core/src/sampler/{source,stream}.rs`,
`crates/daw-app/src/{bank_cache,bank_integrity,sample_bank,stream_loader,meminfo}.rs`.

**SPEC-051 (v0.1.29, PR #66) — маршрутизация шин.** Отправка с шины на шину,
solo/mute на шине, микшерный GUI. Топологическая сортировка порядка шин
считается в `Mixer::new` (вне аудио-пути); `process` без аллокаций —
предвыделенные буферы и фиксированный массив `[BusSend; MAX_BUSES]` на шину.
Solo/mute шины глушит только возврат в мастер: исходящие посылы шины
продолжают идти. Циклы отвергаются при валидации проекта (DFS).

**SPEC-052 (v0.1.30, PR #67) — экспорт микса.** Выбор битности (16/24 бит) и
частоты дискретизации, нормализация по пику к целевому dBFS, прогресс в фоне.
Идёт через существующий offline-render с мастер-цепочкой.
Код: `crates/audio-core/src/wav.rs` (энкодер), `crates/daw-app/src/lib.rs`,
тесты — `crates/daw-app/tests/export.rs`.

**SPEC-053 (v0.1.31, PR #68) — импорт FLAC и OGG Vorbis** рядом с WAV/MP3.
Чисто-Rust декодер (`symphonia`: flac + vorbis + ogg), пользователь ничего не
устанавливает. Стерео и моно, любая частота, FLAC 16/24 бит; `.flac`/`.ogg`/
`.oga` есть в диалогах и в drop-фильтре; битый файл даёт понятную ошибку в UI
без паники. Код: `crates/daw-app/src/audio_file.rs`, фикстуры
`crates/daw-app/tests/data/sine*.flac`, `sine.ogg`.

**SPEC-054 (v0.1.32, PR #69) — темпо-трек / темпо-карта.** Упорядоченные точки
(тик + BPM), первая всегда на тике 0; скалярный `tempo_bpm` стал первой точкой,
старые проекты открываются без изменений, карта сериализуется только при >1
точке. Единый путь конвертации тик↔сэмпл заменил скалярный BPM везде
(метроном, сетка/снап, линейка тактов, MIDI-секвенсор, экспорт). Изменение
темпа ступенчатое, без рамп. `MAX_TEMPO_POINTS = 256`, BPM 30–300.
Realtime: карты строятся вне аудио-пути и передаются через `rtrb`-кольцо, старые
карты возвращаются вторым кольцом и освобождаются на control-потоке; в
аудио-пути нет аллокаций и локов. Код: `crates/audio-core/src/transport.rs`,

|---|---|---|
| 1 | При перетаскивании файла регион встаёт не под курсором (зависит от размера экрана), а не туда, куда указывает мышь | **Исправлено (PR #63).** winit 0.30.13 на X11 не шлёт `CursorMoved` во время внешнего XDND-драга. | 2 | Дроп на существующую дорожку с регионами всегда создаёт новую | **Исправлено (PR #63).** Следствие #1: без верной позиции hit-test дорожки промахивался. Чинится вместе с #1 (единый источник позиции); проверено владельцем вживую. |

| 4 | Приложение на Wayland идёт через XWayland | eframe включён без фичи `wayland`: winit 0.30.13 не умеет DnD на Wayland. Включать нельзя, пока не будет своя реализация. |

Если устройство не открылось, транспорт идёт по тихим часам (`PlaybackEngine::advance_silent` на control-потоке), а в UI — понятная ошибка с причиной и командой установки (нет `libasound` / нет `pipewire-alsa` / нет устройств). ## Используемые технологии

- Rust 2024 edition, toolchain 1.85, workspace из трёх крейтов.
- `eframe`/`egui` 0.33 (glow + x11), `rfd` для диалогов файлов.
- `winit` 0.30.13 из `vendor/winit` с патчем XDND → `CursorMoved` (см. выше).
- `cpal` 0.15 (опционально, фича `realtime`): WASAPI на Windows, ALSA/PipeWire
  на Linux.
- `symphonia` 0.5 (фичи `mp3`, `flac`, `vorbis`, `ogg`) — декодирование MP3,
  FLAC и OGG Vorbis без внешних библиотек; `hound` — WAV; `rtrb` — SPSC-очереди;
  `thiserror` — ошибки.
- Без `serde`: проект хранится в текстовом JSON с разбором руками (SPEC-008).
- `cargo fmt`, `clippy -D warnings`, `cargo test`; GitHub Actions CI и Release.

## Важные решения по архитектуре

1. **Движок не знает про платформу.** `audio-core` не подключает аудиоустройств;
   всё, что трогает ОС, живёт в `daw-app`.
2. **Без `unsafe`.** `#![forbid(unsafe_code)]` в движке и оболочке.
3. **Реальный путь без аллокаций и блокировок.** Параметры сглаживаются,
   команды идут через `rtrb`, переполнение — не паника, а отбрасывание.
   Дорогие структуры (топология шин, темпо-карты) строятся до аудио-пути и
   освобождаются на control-потоке.
4. **Один путь конвертации тик↔сэмпл.** Скалярного BPM больше нет: всё идёт
   через темпо-карту (SPEC-054), поэтому метроном, сетка, линейка и экспорт не
   расходятся между собой.
5. **Golden-тесты — оракул DSP.** `crates/audio-core/tests/golden/*.wav` не
   меняются агентом никогда; расхождение чинится в коде.
6. **Текстовый проект вместо бинарного.** Читаемость и диффы важнее размера.
7. **Офлайн-путь обязателен.** `selftest` и `bounce` работают без звуковой
   карты, поэтому тесты и агенты не зависят от оборудования.
8. **Версия из тега.** `Cargo.toml` не бампается, версия вычисляется из имени
   тега в `release.yml`.
9. **Разделение ролей агентов.** Координатор не пишет код; Opus-сессии
   реализуют; DeepSeek-сессии гоняют гейт и выпускают релизы.
10. **Интерполяция — опция, а не замена.** SPEC-068 шаг A добавляет Hermite
    рядом с линейной; по умолчанию остаётся `Linear`, чтобы goldens и звук не
    менялись без явного решения.
