# Sound Pro

Каркас открытой DAW на Rust для Linux, Windows и macOS, спроектированный так, чтобы с
ним могли продуктивно работать ИИ-агенты: движок тестируется полностью без
звуковой карты, правила для агентов явно записаны, а эталоны звука защищены от
случайной перегенерации.

## Скачать

Готовые сборки лежат на странице
[Releases](https://github.com/saytomorrow-st/sound-pro/releases) (SPEC-024):

- **Linux** — `Sound-Pro-<версия>-x86_64.AppImage`: сделайте файл
  исполняемым (`chmod +x`, или «Свойства → Разрешить запуск») и запустите.
  AppImage самодостаточен: в нём лежит `libasound.so.2` и ALSA-плагины для
  PipeWire/PulseAudio, поэтому ничего устанавливать не нужно (sudo не
  требуется, `alsa-lib-devel` не нужен).
- **Windows** — `Sound-Pro-<версия>-windows-x86_64.zip`: распакуйте и
  запустите `sound-pro.exe`.
- **macOS** — `Sound-Pro-<версия>-macos-<arch>.dmg`: перетащите Sound Pro в
  «Программы». Приложение подписано ad-hoc (без Apple Developer ID), поэтому
  при первом запуске откройте его через правый клик → «Открыть».

### Получить и запустить одной командой

Скачать последний релизный AppImage со звуком и положить его в папку
«Загрузки» (без установки Rust и ALSA):

```bash
scripts/dev-appimage.sh
```

Этот скрипт по умолчанию скачивает готовый самодостаточный AppImage из
GitHub Releases. Локальная сборка из исходников — `scripts/dev-appimage.sh
--build` (требует Rust и, для звука, ALSA dev-заголовков; при их отсутствии
скрипт печатает понятное сообщение и предлагает скачать готовый артефакт).

## Окно приложения

```bash
cargo run --release --bin sound-pro              # пустой проект
cargo run --release --bin sound-pro -- song.json # открыть проект
cargo run --release --bin sound-pro --features audio -- song.json # со звуком
```

Файл → Импорт WAV добавляет дорожку с клипом (или клип на выбранную дорожку),
слева — громкость, панорама, M/S, внизу — мастер. Клик выбирает клип, `Delete`
удаляет, `Ctrl`+колесо — масштаб, `Ctrl+S/O/I` — сохранить/открыть/импорт.
Файл → Экспорт сведения пишет стерео WAV. Сверху — транспорт: «В начало»,
«Играть/Пауза», «Стоп», время и такт; пробел — играть/пауза, `Home` — в
начало, клик по линейке переставляет курсор. Звук идёт в устройство по
умолчанию при сборке с `--features audio` (Linux: `libasound2-dev`); без неё
окно собирается без системных библиотек, но молчит.

## Быстрый старт

```bash
cargo test --workspace --all-targets
cargo run -q --bin daw -- selftest
cargo run -q --bin daw -- bounce tone.wav 1.0
cargo run -q --bin daw -- bounce take.wav 30.0 --split 48000   # части по 1 с
```

Реальный аудиовыход (CPAL; Linux: `libasound2-dev`, Windows и macOS: без зависимостей):

```bash
cargo build -p daw-app --features realtime
```

## Что уже работает

- Транспорт: play/stop/seek/rewind, темп, тактовый размер, тики PPQN 960.
- Граф: резервируемая ёмкость, суммирование, ошибки вместо паник на горячем пути.
- Offline-рендер с независимостью от размера кванта; golden-тесты.
- WAV float32/PCM16, CLI-смок (`selftest`, `bounce`).
- Инкрементальная запись (`Recorder`) с разбиением на части — длинный bounce
  не держится в памяти целиком (SPEC-002).
- SPSC-очередь команд UI → аудио (SPEC-003), парсер MIDI SMF (SPEC-004).
- Realtime-бэкенд на CPAL (`daw play`, фича `realtime`) — SPEC-005.
- [Документ проекта](docs/PROJECT.md): сессия как JSON без `serde`
  (`daw project save|show`) — SPEC-008.
- [Полифонический синтезатор](docs/SYNTH.md): 16 голосов, ADSR, MIDI-файл →
  WAV (`daw render-midi`) — SPEC-009.
- [Сессии и клипы](docs/SESSION.md): дорожки, окна в источники, рендер суммы
  (`daw render-session`) — SPEC-010.
- Клипы из WAV-файлов и сведение сохранённого проекта
  (`daw session render <project.json> <out.wav>`) — SPEC-014.
- Окно `sound-pro`: таймлайн, микшер, проект, импорт и экспорт — SPEC-015.
- Воспроизведение в окне: транспорт, бегущий курсор, звук — SPEC-016.
- Редактирование клипов мышью: перетаскивание по времени и между дорожками,
  обрезка краёв, привязка к сетке (Shift — без привязки) — SPEC-017.
- Отмена и повтор всех правок: Ctrl+Z, Ctrl+Shift+Z (или Ctrl+Y), меню
  «Правка»; одно перетаскивание — один шаг — SPEC-018.
- WAV любой частоты (44100, 96000 Гц…) импортируется и переводится в частоту
  проекта — SPEC-019.
- Запись с микрофона: кнопка ⏺ или клавиша R, запись ложится клипом
  `rec-NNN.wav` в папку `audio` рядом с проектом — SPEC-020.
- MIDI-дорожки: «Дорожка → Новая MIDI-дорожка», двойной клик открывает
  piano roll; клик рисует ноту, правый клик удаляет, перетаскивание
  двигает. Ноты играет встроенный синтезатор — SPEC-021.
- Эффекты: кнопка «FX» у дорожки открывает окно, где можно добавить
  эквалайзер, компрессор и реверб (до 8 штук), менять порядок, включать
  обход и крутить ручки на слух — SPEC-022.
- Автоматизация: кнопка «A» у дорожки показывает линию громкости или
  панорамы (переключатель рядом). Клик ставит точку, перетаскивание двигает,
  правый клик удаляет; пока линия не пуста, её ползунок неактивен — SPEC-023.
- Цикл: протяните мышью по линейке тактов — появится жёлтая полоса, и
  воспроизведение будет повторять этот участок без разрыва. Кнопка 🔁 или
  клавиша C включает и выключает цикл; Shift — без привязки к долям — SPEC-025.
- Метроном: кнопка 🎵 или клавиша K — щелчки на каждой доле, первая доля такта
  выше. Темп (BPM) и размер такта меняются полями в транспорте; размер
  сохраняется в проекте — SPEC-026.
- Клипы: S разрезает выделенный клип по курсору, Ctrl+C / Ctrl+V копируют
  и вставляют клип на выделенную дорожку в место курсора, Ctrl+D ставит копию
  сразу после клипа. Те же команды есть в меню «Правка» — SPEC-027.
- Шины: кнопка «Шины» открывает окно, «+ Шина» создаёт общую шину с
  реверберацией; выберите дорожку и поднимите ползунок посыла — несколько
  дорожек звучат в одном зале. FX у шины меняет её эффекты — SPEC-028.
- Дорожки: двойной щелчок по имени — переименовать; правый щелчок по
  заголовку — цвет, «Выше», «Ниже», «Дублировать», «Удалить» — SPEC-029.
- Маркеры: M или «+ Маркер» — метка у курсора; щелчок по флажку — переход,
  перетаскивание — перенос, правый щелчок — переименовать/удалить; `,` и `.` —
  к соседним меткам — SPEC-030.
- После конца песни курсор возвращается в начало, а новая MIDI-дорожка
  встаёт в начало такта, а не за концом звука — SPEC-031.
- WAV и MP3: «Импорт» или перетаскивание файла на дорожку (клип под мышью)
  или ниже дорожек (новая дорожка) — SPEC-032.
- «Файл → Настройки звука…»: выбор выхода, входа и размера буфера;
  сохраняется между запусками — SPEC-033.
- Окно в стиле студии: панель с дисплеем позиции, инспектор, библиотека,
  браузер, внизу микшер (X), редактор нот (E) и быстрые регуляторы (B);
  ещё не готовые части — неактивные заглушки — SPEC-034.
