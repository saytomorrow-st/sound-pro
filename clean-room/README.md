# Журнал чистой комнаты

## Как устроено

| Роль | Что делает | Что видит |
|---|---|---|
| «Грязная» команда | Изучает поведение: UI по видео/мануалам, форматы по публичным спецификациям, наблюдаемые входы/выходы | продукт, документация |
| «Чистая» команда | Реализует по спецификациям | только `specs/` и этот журнал |

**Запрещено:** дизассемблирование, декомпиляция, чтение исходников, копирование
ассетов, пресетов, сэмплов, иконок; использование товарных знаков; воспроизведение
внешнего вида продукта «один в один».

## Журнал

Формат записи (добавляйте в конец):

```
## YYYY-MM-DD — <тема>
Сторона: dirty | clean
Участник: <имя/роль>
Источники, прочитанные/просмотренные: <список>
Переданные артефакты: specs/NNN.md, <другие>
Замечания: <что подтверждено, что осталось открытым>
```

## Правила для ИИ-агентов

- Агент, работающий в рамках «чистой» команды, **не** должен получать в контекст
  скриншоты, видео или описания UI, не прошедшие через спецификацию.
- Каждая спецификация, сгенерированная с участием ИИ, фиксируется здесь: модель,
  промпт (или его суть), источник утверждений.
- Агент «грязной» команды не коммитит код в этот репозиторий.
