# SPEC-015: окно приложения

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Всё, что умеет движок, доступно только из командной строки. Пользователь не
видит дорожек и клипов, не может собрать проект из файлов мышью и свести его.

## Поведение

Новый крейт `crates/daw-gui`, бинарник `sound-pro`. Окно на `eframe`/`egui`
(чистый Rust, Linux X11/Wayland и Windows), файловые диалоги — `rfd`.
Внешний вид и названия свои; чужие ресурсы, иконки и тексты не используются.

### Модель редактора (`daw_gui::Editor`, без окна, покрыта тестами)

- `Editor::new()` — пустой проект `untitled`, 48000 Гц, 120 BPM, без дорожек,
  без пути, `is_dirty() == false`.
- `open(path)` читает проект (`Project::from_json`), запоминает путь и
  загружает волны всех клипов с `source`. Клип без файла или с битым файлом
  не мешает открытию: у него просто нет волны. Ошибка чтения или разбора —
  `EditorError`, текущий проект при этом не меняется.
- `import_wav(path)` добавляет новую дорожку с именем файла (без расширения)
  и одним клипом на всю длину файла с позиции 0. Если выбрана дорожка —
  клип добавляется на неё, сразу после её последнего клипа. Путь хранится
  абсолютным. Ошибки: файл не читается, частота файла ≠ частоте проекта
  (`SampleRate`), пустой файл, превышен `MAX_TRACKS`/`MAX_CLIPS_PER_TRACK`.
  При ошибке проект не меняется.
- `save_as(path)` пишет JSON. Пути файлов, лежащих внутри каталога проекта,
  пишутся относительными (с `/`), остальные — абсолютными. После сохранения
  `is_dirty() == false`, путь проекта = `path`. Невалидная сессия не пишется.
- `delete_clip(track, clip)`, `delete_track(track)`, изменения микшера
  (`track_mut`, `set_master_gain`) помечают проект изменённым. Индексы вне
  диапазона игнорируются.
- `export(out)` сводит текущий проект в стерео WAV через
  `daw_app::load_session` + `render_session`. Пустой проект — ошибка `Empty`.
- `Peaks` — минимум/максимум по блокам фиксированного размера для отрисовки
  волны; хвост короче блока образует последний блок.

### Окно

- Меню «Файл»: Новый, Открыть…, Сохранить, Сохранить как…, Импорт WAV…,
  Экспорт сведения…, Выход.
- Слева заголовки дорожек: имя, M (mute), S (solo), громкость, панорама.
- Таймлайн: линейка тактов по темпу (4/4), клипы прямоугольниками с волной
  и именем. Клик выбирает клип и дорожку, `Delete` удаляет выбранный клип.
  Колесо с `Ctrl` меняет масштаб.
- Внизу: мастер-громкость и строка состояния (последняя ошибка или действие).
- Заголовок окна: `Sound Pro — <имя файла>` и `*`, если есть изменения.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Импорт WAV 44100 Гц в проект 48000 Гц | `SampleRate`, проект не меняется |
| Импорт пустого WAV | `EmptyFile` |
| 33-я дорожка | `Session(TooManyTracks)`, проект не меняется |
| Открыть проект, у клипа нет файла | открывается, клип без волны |
| Сохранить проект с файлом в подкаталоге | путь `audio/x.wav` |
| Экспорт пустого проекта | `Empty` |

## Критерии приёмки

- [x] Интеграционные тесты `crates/daw-gui/tests/editor.rs` на модель.
- [x] Сохранённый окном проект сводится `daw session render` так же.
- [x] Окно собирается на Linux и Windows в CI без системных библиотек.
- [x] Движок (`audio-core`) не меняется.
