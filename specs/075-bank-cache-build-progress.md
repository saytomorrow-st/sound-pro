# SPEC-075: индикатор прогресса фоновой сборки кэша банка в GUI

Статус: ready
Владелец: saytomorrow-st
Для агента: разрешено реализовывать

## Проблема

RFC-002 (`docs/rfc/002-sample-streaming.md`) влит: для старых банков PCM-кэш
строится в фоне (`crates/daw-app/src/bank_cache.rs`, `sample_bank.rs`), но
прогресс сейчас только пишется в лог (`bank {id}: building cache
{done}/{total} samples, …`). Пользователь, выбравший такой банк в инспекторе,
видит лишь индикатор «Загрузка {name}…» (SPEC-066) и не понимает, сколько ещё
ждать: сборка крупного банка занимает заметное время, а UI остаётся без
обратной связи о доле выполненной работы.

## Поведение

1. Прогресс сборки кэша передаётся из воркер-потоков в UI через атомарные
   счётчики (образец — `bank_download::Progress`, SPEC-067), без блокировок,
   без `Mutex` на горячем пути и без изменений в аудио-пути
   (`Graph::process`/`Renderer::render` не затрагиваются).
2. Новый тип `daw_app::sample_bank::CacheBuildProgress` хранит `done` (сколько
   уникальных сэмплов декодировано) и `total` (сколько всего) в
   `Arc<AtomicU64>`; он `Clone` и `Send`. `fraction()` возвращает
   `0.0..=1.0`, `0.0` пока `total` неизвестен/равен нулю.
3. `load_bank_auto_with_progress` и `preload_bank_with_progress` принимают
   `Option<&CacheBuildProgress>`; `None` сохраняет прежнее поведение (только
   лог). Существующие `load_bank_auto`, `load_bank_auto_with_budget` и
   `preload_bank` остаются и делегируют в новые функции с `None`.
4. GUI (`daw-gui`) при запуске фоновой загрузки банка
   (`App::start_bank_load`) создаёт `CacheBuildProgress`, передаёт клон в
   воркер и хранит оригинал в `pending_bank_load`. Пока банк грузится,
   индикатор в инспекторе (`shell.rs`) показывает долю: при
   `0 < fraction < 1` — «Кэш {name}: {N}%…», иначе — прежний «Загрузка
   {name}…».

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| `total == 0` (план ещё не известен / нет сэмплов) | `fraction() == 0.0`, деления на ноль нет |
| сборка уже завершена, `done == total` | `fraction() == 1.0` |
| кэш уже готов (банк грузится из кэша) | прогресс не обновляется, индикатор как раньше |
| `progress == None` | поведение идентично прежнему (только лог) |
| клон `CacheBuildProgress` в другом потоке | атомарные счётчики видны всем клонам |
