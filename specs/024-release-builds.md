## Проблема

Чтобы попробовать Sound Pro, сейчас нужно поставить Rust, ALSA-заголовки и
собрать проект из исходников. Обычный пользователь так делать не будет. Нужны
готовые файлы: скачал — запустил.

## Поведение

### Что получает пользователь

- **Linux**: `Sound-Pro-<версия>-x86_64.AppImage` — один файл, запускается
  после `chmod +x` на любом дистрибутиве с glibc не старше, чем в Ubuntu
  22.04. Окно со звуком (фича `audio`).
- **Windows**: `Sound-Pro-<версия>-windows-x86_64.zip` с `sound-pro.exe`,
  README и лицензиями. Окно со звуком, без лишнего чёрного окна консоли.

### Как это собирается

- Workflow `.github/workflows/release.yml`:
  - на тег `v*` — собирает оба файла и публикует их в GitHub Release этого
    тега;
  - вручную (`workflow_dispatch`) и в PR, меняющих `packaging/**` или сам
    workflow, — собирает и кладёт файлы в артефакты запуска, ничего не
    публикуя.
- Версия — из тега без `v` (`v0.2.0` → `0.2.0`), иначе из `Cargo.toml`.
- AppImage собирает `packaging/linux/build-appimage.sh <бинарник> <версия>
  <папка>`: AppDir с `AppRun`, `.desktop`-файлом и иконкой, затем
  `appimagetool`. Скрипт работает и локально.
- Иконка — `packaging/sound-pro.svg` (своя, нарисована с нуля).
- Сборка Linux идёт на `ubuntu-22.04`, чтобы AppImage работал на старых
  системах.

### Окно

- На Windows бинарник `sound-pro` в release-сборке собирается как GUI-
  приложение (`windows_subsystem = "windows"`): консоль не открывается.
  Отладочная сборка оставляет консоль для сообщений.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Нет аудиоустройства | окно открывается, статус «звук недоступен» (как раньше) |
| PR без изменений в `packaging/` | release-workflow не запускается |
| Запуск вручную | файлы в артефактах, релиз не создаётся |
| Скрипт без аргументов | подсказка и код 2 |

## Критерии приёмки

- [ ] Локально `build-appimage.sh` даёт AppImage, который открывает окно.
- [ ] В PR release-workflow зелёный на Linux и Windows, артефакты есть.
- [ ] README объясняет, где скачать и как запустить.
- [ ] Gate зелёный; goldens не тронуты.

## Вне области
