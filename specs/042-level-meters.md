# SPEC-042: Индикаторы уровня

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Индикаторы на фейдерах рисуются «для вида»: высота считается из положения
фейдера, а не из звука. Нельзя увидеть, какая дорожка звучит, где пик и
перегружен ли мастер.

## Поведение

### Банк измерителей (`daw_app::meters::Meters`)

- `Meters::new()` выделяет атомики сразу на `MAX_TRACKS` дорожек (по два
  канала) и мастер; клон (`Clone`) — тот же банк (`Arc`). Банк один на
  плеер и переживает замены графа (SPEC-035).
- Аудиопоток: `record_track(track, left, right)` и
  `record_master(left, right)` запоминают максимум `|sample|` с прошлого
  чтения (`f32` в `AtomicU32`, `fetch_max` по битам неотрицательного
  числа). Без аллокаций, блокировок и паник; `NaN`/∞ не записываются;
  дорожка с номером `>= MAX_TRACKS` игнорируется. `right = None` (моно) —
  правый канал равен левому.
- Окно: `take_track(track)` / `take_master()` возвращают `(left, right)` и
  обнуляют значения (`swap(0)`). Чужая дорожка — `(0, 0)`.

### Где измеряется

- Дорожка (`nodes::Track`): после эффектов, громкости, панорамы и
  автоматизации — пост-фейдер, но **без** мастер-громкости (как в Logic:
  мастер не двигает индикаторы каналов). Заглушённая дорожка — тишина.
  Подключается `Track::with_meter(meters, index)`.
- `build_session_graph_metered(job, Some(&meters))` подключает банк к
  каждой дорожке, с шинами и без; `build_session_graph(job)` — то же с
  `None`, звук бит-в-бит прежний, goldens не меняются.
- Мастер: `PlaybackEngine::with_meters(meters)`; `fill` записывает каждый
  отрендеренный квант (без щелчка метронома).

### Показ (`daw_gui::layout::MeterState`)

- `update((left, right), dt)`: уровень растёт сразу, падает не быстрее
  `METER_FALL_DB_PER_S = 26` дБ/с; ниже `FADER_FLOOR_DB` — ноль.
- Удержание пика: максимум держится `METER_HOLD_SECONDS = 1.5` с, затем
  падает с той же скоростью.
- `peak` — максимум с последнего сброса, `clipped()` — `peak >= 1.0`
  (0 dBFS), `reset_peak()` сбрасывает.
- `is_idle()` — всё погасло, перерисовка не нужна.
- Цвет: зелёный ниже −6 dB, жёлтый от −6 до 0, красный от 0 dB.

### Окно

- Фейдеры каналов, шин и мастера: стереоиндикатор (два столбика) с
  отметкой пика; над фейдером — максимум в дБ, красный при перегрузке,
  щелчок сбрасывает. Шины пока без собственного измерения — индикатор
  пустой.
- Заголовок дорожки: тонкий горизонтальный стереоиндикатор внизу.
- Индикаторы гаснут плавно после остановки.

## Критерии приёмки

- [x] `record_*` / `take_*` дают максимум модуля и обнуляют; моно — копия.
- [x] Дорожка с банком в графе (с шинами и без) пишет уровень пост-фейдер,
      без мастера; заглушённая — ноль.
- [x] Граф без банка звучит бит-в-бит как с банком.
- [x] Мастер-уровень пишет `PlaybackEngine::fill`.
- [x] `fill` и граф с банком не аллоцируют.
- [x] Баллистика: мгновенный рост, спад 26 дБ/с, удержание 1.5 с, сброс пика.
