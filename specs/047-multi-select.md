# SPEC-047: Выделение нескольких регионов и дорожек

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

На таймлайне можно было выделить только один регион и одну дорожку. В Logic Pro
регионы выделяются группой (Shift/Ctrl-клик, рамка, Ctrl+A), группу можно
удалить или передвинуть одним действием, а дорожки выделяются по Ctrl/Shift.

## Цель

Множественное выделение регионов и дорожек; групповые удаление и перемещение
одним шагом отмены.

## Критерии приёмки

### §1 Клик и переключение
- Клик по региону выделяет только его (основной регион).
- Shift/Ctrl-клик добавляет регион в выделение или убирает его; если убран
  основной, основным становится первый из оставшихся.
- Клик по пустому месту без модификатора снимает выделение регионов.

### §2 Рамка
- Протяжка инструментом «Указатель» по пустому месту рисует рамку.
- Выделяются регионы, пересекающие рамку по времени `[from, to)` и по
  дорожкам. Без модификатора выделение заменяется, с Shift/Ctrl — дополняется.

### §3 Групповое удаление
- Delete удаляет все выделенные регионы одним шагом отмены.

### §4 Групповое перемещение
- Перетаскивание любого выделенного региона двигает всю группу, сохраняя
  взаимные смещения, по времени и по дорожкам, одним шагом отмены.
- Сдвиг ограничивается: самый ранний регион не уходит левее 0, группа не
  выходит за первую/последнюю дорожку.

### §5 Выделение дорожек
- Клик по заголовку дорожки или каналу микшера выделяет дорожку;
  Ctrl — переключает, Shift — диапазон до основной дорожки.

### §6 Ctrl+A
- Ctrl+A (вне текстового поля) выделяет все регионы.

## Граничные случаи

- После отмены/повтора выделение очищается от несуществующих регионов/дорожек.
- Перемещение без выделения возвращает ошибку `NoClip`.
- Удаление дорожки сбрасывает выделение дорожек и регионов.
