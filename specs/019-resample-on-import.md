# SPEC-019: Ресемплинг при импорте

Статус: ready
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Проект работает на одной частоте (по умолчанию 48000 Гц). WAV-файл с другой
частотой (44100, 96000 Гц и т. д.) сейчас отклоняется ошибкой «sample rate …».
Большинство файлов в мире записаны на 44100 Гц, поэтому импорт почти всегда
падает.

## Поведение

### Функция `audio_core::resample::resample(input, from, to)`

- Возвращает `Result<Vec<f32>, ResampleError>`. Только для офлайн-работы
  (загрузка файлов); аудиоколбэк её не вызывает.
- `from == 0` или `to == 0` → `ResampleError::ZeroRate`.
- `from == to` → копия входа, бит в бит.
- Длина выхода: `ceil(len * to / from)`. Пустой вход → пустой выход.
- Метод: оконный sinc (Julius O. Smith, «Digital Audio Resampling»), окно
  Блэкмана, 32 перехода через ноль на сторону, срез `0.95 · min(from, to) / 2`.
  Ядро берётся из таблицы с линейной интерполяцией. Отсчёты за краями входа
  считаются нулями.
- Синус 1 кГц, 44100 → 48000: в середине сигнала совпадает с идеальным синусом
  на 48000 с точностью `1e-3`.
- Постоянный сигнал 1.0 остаётся 1.0 (±`1e-3`) вдали от краёв.
- Понижение 96000 → 48000: тон 30 кГц (выше новой частоты Найквиста)
  подавляется до RMS < 0.01 (−40 дБ).
- Результат детерминирован: одинаковый вход — одинаковые биты.

### Импорт в редакторе (`Editor::import_wav`)

- Файл с другой частотой больше не ошибка: звук переводится в частоту
  проекта. `source_length` клипа и его пики считаются в отсчётах проекта
  (44100 отсчётов при 44100 Гц → клип 48000 отсчётов при 48000 Гц).
- Файл в проекте указывает на исходный WAV; сам файл не меняется и копия не
  создаётся.

### Загрузка проекта (`daw_app::load_session`)

- Клип, чей файл записан с другой частотой, переводится в частоту сессии при
  загрузке, затем обрезается до `source_length`. Если после перевода отсчётов
  меньше, чем `source_length`, — `LoadError::SourceTooShort` (с длиной после
  перевода).
- Варианты ошибок `LoadError::SampleRate` и `EditorError::SampleRate`
  удаляются: такой ситуации больше нет.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| `from == to` | копия бит в бит |
| пустой вход | пустой выход |
| 1 отсчёт, 44100 → 48000 | 2 отсчёта (`ceil(48000/44100)`) |
| частота 0 | `ResampleError::ZeroRate` |
| стерео-файл с другой частотой | сначала сведение в моно, затем перевод |

## Критерии приёмки

- [ ] Юнит-тесты резамплера на каждое утверждение выше.
- [ ] Тест редактора: импорт 44100 Гц даёт клип нужной длины и пиков.
- [ ] Тест загрузки: файл 44100 Гц звучит в рендере сессии 48000 Гц.
- [ ] Goldens не меняются.
- [ ] fmt, clippy, test зелёные.

## Вне области

- Кэш переведённого звука (сейчас перевод выполняется при каждой загрузке).
- Выбор качества ресемплинга.
- Смена частоты самого проекта.
