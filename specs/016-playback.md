## Проблема

Окно (SPEC-015) показывает проект и сводит его в файл, но услышать проект
нельзя. Нет кнопок транспорта и курсора воспроизведения.

## Поведение

### Движок воспроизведения (`daw_app::playback`, без устройства, покрыт тестами)

- `playback(graph, sample_rate, start, end)` возвращает пару
  `(PlaybackControl, PlaybackEngine)`. Очередь команд и буферы выделяются
  здесь, а не в аудиоколбэке. Транспорт стоит на `start`, остановлен.
- `PlaybackControl` живёт в потоке окна: `play()`, `stop()`, `seek(frames)`,
  `position()`, `is_playing()`. Команды идут через `CommandQueue` (rtrb),
  позиция и состояние читаются из атомиков. Полная очередь — команда
  отбрасывается, `play/stop/seek` возвращают `false`.
- `PlaybackEngine::fill(out, channels)` вызывается из аудиоколбэка: рендерит
  `out.len() / channels` кадров кусками не больше 1024, раскладывает их
  по каналам устройства (`interleave_into`), публикует позицию. Не
  аллоцирует, не блокирует, не паникует; ошибка рендера даёт тишину до конца
  буфера.
- Когда позиция доходит до `end`, движок сам останавливается: остаток буфера —
  тишина, `is_playing() == false`, позиция = `end`.
- Звук через движок совпадает по сэмплам с офлайн-сведением того же графа,
  при любых размерах буфера устройства.

### Устройство (`daw_app::realtime::start_output`, фича `realtime`)

- Открывает устройство вывода по умолчанию на частоте проекта. Если
  устройство не умеет эту частоту — `RealtimeError::SampleRate`, без
  ресемплинга. Нет устройства — `NoDevice`. Окно не падает, ошибка идёт в
  строку состояния.

### Модель окна (`daw_gui`)

- `Editor::playback(start)` строит пару из текущего проекта (громкость, mute,
  solo, панорама берутся на момент вызова). Пустой проект — `Empty`. Если
  `start` за концом проекта, воспроизведение начинается с 0.
- `samples_to_x` / `x_to_samples` переводят позицию в пиксели таймлайна и
  обратно при заданном масштабе (пикселей в секунду); x левее начала — 0.
- `clock(samples, rate)` — строка `м:сс.ммм`; `bars(samples, rate, tempo)` —
  `такт.доля` (4/4, с 1).

### Окно

- Панель транспорта: «В начало», «Играть/Пауза», «Стоп», время и такт.
- Пробел — играть/пауза; `Home` — в начало.
- Курсор воспроизведения — вертикальная линия на таймлайне, бежит во время
  игры. Клик по линейке ставит курсор туда (и во время игры тоже).
- «Стоп» останавливает; повторный «Стоп» на месте — в начало.
- Изменения микшера и клипов во время игры слышны после следующего
  «Играть» (живые параметры — отдельная задача).
- Сборка без звука (без фичи `audio`) показывает в статусе, что звук
  выключен в этой сборке.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Пустой проект, «Играть» | `Empty` в статусе, ничего не играет |
| Курсор за концом проекта, «Играть» | старт с 0 |
| Позиция дошла до конца | остановка, курсор на конце |
| Буфер устройства 3000 кадров | рендер кусками 1024+1024+952, звук совпадает с офлайн |
| Нет звуковой карты | ошибка в статусе, окно работает |
| Частота устройства ≠ частоте проекта | `SampleRate` в статусе |
| Переполнена очередь команд | команда не применяется, `false` |
