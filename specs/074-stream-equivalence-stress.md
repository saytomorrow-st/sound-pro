# SPEC-074: Эквивалентность, стресс и SyncStream (RFC-002 этап 7)

Статус: ready
Владелец: saytomorrow-st
Для агента: разрешено реализовывать

## Проблема

Этапы 5–6 (SPEC-072, SPEC-073) дали `VoiceStream`, загрузчик и Streaming в
движке, но эквивалентность с Resident проверена на нескольких сценариях, а
поведение при перегрузке (много голосов, медленный/зависший загрузчик) — нет.
Офлайн-рендер Streaming-банка должен гарантированно не давать underrun
(RFC-002 §9 «SyncStream»), в том числе на высоких транспозициях.

## Поведение

### Эквивалентность (`audio-core/tests/sampler_stream_equivalence.rs`)

Движок с `SampleSource::Streaming` и синхронно отвечающим загрузчиком
рендерит бит-в-бит как с `SampleSource::Resident` на одном и том же PCM.
Сценарии: аккорд обычных нот, note-off во время стриминга, петли (несколько
проходов, `loop_start` в голове и `loop_start = 0`), кража голоса при
переполнении пула, `reset` посреди рендера, повторный запуск ноты (тот же
слот, новая `generation`). Каждый сценарий — для `Linear` и `Hermite4`.
Во всех сценариях `underruns == 0`.

### Стресс «педаль 128 голосов» (`audio-core/tests/sampler_stream_stress.rs`)

128 голосов (`MAX_SAMPLER_VOICES`), новые ноты каждые 64 кадра, загрузчик
по фазам: полный сервис → медленный → заблокирован → случайный голод и
повтор устаревших блоков (без проверки `is_current`) → `reset` → загрузчик
пропал. Второй вариант — настоящий поток загрузчика со случайными
`sleep`. Ожидается:

- на аудиопотоке ноль аллокаций (счётчик аллокатора по потоку);
- вывод конечен и ограничен, нет паник;
- underrun ведёт только к fade-out (`STEAL_FADE_SAMPLES`), без щелчков
  и пауз; есть кражи голосов;
- устаревшие блоки отбрасываются по `generation` (`stale_blocks > 0`),
  гонка `cancel`/`rewind` с загрузчиком не ломает кольца;
- после `reset` и в конце `active_streams() == 0`; без загрузчика — тишина.

### `VoiceStream::cancel`

Если заголовок блока уже снят с кольца, но блок прочитан не до конца,
`cancel` пропускает его непрочитанные сэмплы. Иначе остаток сдвигал
следующие блоки повторно занятого слота (`push_block → Full`, неверный PCM).

### SyncStream (`daw-app`, `SamplerInstrument::render_notes`)

Офлайн-рендер Streaming-банка — синхронный: перед каждым чанком
вызывается `StreamLoader::pump` в том же потоке. Длина чанка
`min(1024, ⌊RING_FRAMES / 4 / r_max⌋)`, где `r_max` — наибольший
`playback_ratio` среди регионов, покрывающих ноты рендера (≥ 1). Голос
перезапрашивает данные, когда в кольце осталось меньше половины, поэтому
за чанк он не съедает больше четверти кольца и underrun невозможен.
Отдельного режима источника нет: SyncStream — это способ обслуживать
тот же `Streaming`.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Транспозиция вверх на 5 октав (ratio 32) | чанк 256 кадров, underrun = 0 |
| Загрузчик заблокирован | голоса затухают за `STEAL_FADE_SAMPLES`, без паники |
| Блок пришёл после `cancel`/`rewind` | отбрасывается (`stale_blocks`) |
| `cancel` посреди блока | непрочитанный остаток пропущен |
| Загрузчик пропал навсегда | тишина после затухания, слоты свободны |

## Критерии приёмки

- [ ] 6 сценариев эквивалентности × 2 интерполяции — бит-в-бит.
- [ ] Стресс (детерминированный и с потоком загрузчика): 0 аллокаций,
      `underruns > 0`, `stolen > 0`, тишина в конце, `active_streams == 0`.
- [ ] Регрессионный юнит-тест `cancel` посреди блока.
- [ ] `SamplerInstrument` из Streaming-банка при плотной полифонии с
      транспозицией до +60 полутонов рендерит бит-в-бит как Resident.
- [ ] fmt, clippy `-D warnings`, `cargo test --workspace --all-targets`
      зелёные; golden WAV не изменены.
