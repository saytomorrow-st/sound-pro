# SPEC-061: MIDI-редактор — квантизация и велосити мышью

Статус: draft
Владелец: saytomorrow

## Проблема

Piano roll (SPEC-021) умеет добавлять, удалять и сдвигать ноты, но не умеет
выравнивать их по музыкальной сетке (квантизация) и менять силу удара
(велосити) мышью. Музыкант вынужден ровнять ноты и задавать акценты вручную,
а велосити меняется только фиксированным сдвигом через существующий
`offset_velocity` (SPEC-043 §3), который не виден и не редактируется мышью.

## Поведение

### Квантизация

Чистая функция в `daw_gui` (тестируемая, без GUI-зависимостей) вычисляет
новую позицию ноты на сетке. Сетка задаётся долей доли:

- целые `1/4`, `1/8`, `1/16`, `1/32`;
- триоли `1/4T`, `1/8T`, `1/16T`, `1/32T` (длина шага = доля / 3).

Вход: абсолютная позиция начала ноты в сэмплах, текущая длина ноты, длина
содержимого клипа, `TempoMap`, параметры (деление, режим, сила). Выход —
пара `(start, length)`. Преобразование идёт через существующую темпо-карту
`audio_core::TempoMap` (тики ↔ сэмплы), без второго пути.

- Шаг сетки в тиках: `TPQN / division` для целых, `TPQN * 3 / division`
  для триолей (по `audio_core::transport::TPQN` = 960).
- `start-only`: длина ноты не меняется.
- `start+length`: конец ноты (`start + length`) квантизуется тем же шагом,
  длина пересчитывается как `квантизованный_конец − квантизованный_старт`.
- `strength` 0–100 %: новая позиция = `snapped + (original − snapped) ·
  (1 − strength/100)`, округление к ближайшему. 100 % — полная привязка,
  0 % — нота не двигается.
- Нота короче одного шага сетки не схлопывается в ноль: результирующая длина
  всегда `>= 1`; для `start+length` при равенстве концов длина принудительно
  `1`.
- Результат всегда внутри содержимого клипа: старт `>= 0`, конец
  `<= source_length`, иначе старт/конец зажимаются.

Публичный метод `Editor::quantize_selection(track, clip, params) ->
Result<(), EditorError>` применяет функцию к выбранным нотам (если выбранных
нет — ко всем нотам клипа) одним шагом отмены, проект помечается изменённым.
Выбор нот хранится в GUI (см. ниже), передаётся в метод списком индексов или
диапазоном.

Параметры квантизации хранятся в GUI: деление, режим, сила. Не сохраняются в
проект.

### Велосити мышью

Под piano roll рисуется велосити-лейн: одна вертикальная полоса на каждую
ноту, высота полосы пропорциональна `velocity` (1–127), полосы расположены по
`start` ноты и раскрашены цветом дорожки (ноты в сетке сверху подкрашиваются
по силе).

- Перетаскивание полосы меняет велосити ноты в диапазон 1–127; значение под
  курсором — непрерывное, округляется к ближайшему.
- Множественный выбор: перетаскивание одной выбранной полосы масштабирует
  остальные выбранные ноты пропорционально (отношение их исходных
  велосити сохраняется), каждая зажата в 1–127.
- Одно действие отмены на всё перетаскивание (не на каждый кадр): велосити
  применяются в `drag_stopped`, а не пока идёт перетаскивание. Пока идёт
  перетаскивание, рисуется предпросмотр.
- Ноты в piano roll подкрашиваются по велосити: яркость/насыщенность растёт
  от 1 до 127.

Публичный метод `Editor::set_note_velocity(track, clip, index, velocity)` —
меняет силу одной ноты (1–127), один шаг отмены. Масштабирование
множественного выбора делает GUI через один вызов, обновляющий все выбранные
ноты разом (одна команда).

### Выбор нот

В GUI заводится состояние выбора нот в открытом piano roll: `Vec<usize>` (или
эквивалент) индексов выбранных нот. Клик по ноте выделяет её (с Ctrl —
добавляет/убирает из выбора). Пустой выбор = «все ноты клипа» для
квантизации.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Пустой выбор при квантизации | квантизуются все ноты клипа |
| Нота короче шага сетки (`start+length`) | длина не становится 0, минимум 1 |
| Нота пересекает границу клипа | результат зажат в `[0, source_length]` |
| Сила 0 % | ноты не двигаются (результат == вход) |
| Сила 100 % | полная привязка к сетке |
| Триоль при некратном шаге | округление к ближайшему сэмплу |
| Велосити ниже 1 / выше 127 | зажимается в 1–127 |
| Множественный выбор + пропорция | масштабирование с сохранением отношений |
| Отмена/повтор | точное восстановление тиков и велосити |
| Сохранение/загрузка проекта | велосити сохраняются (поле `velocity` уже есть) |

## Критерии приёмки

- [ ] Юнит-тесты чистой функции квантизации: целые и триоли, оба режима,
      силу 0/50/100 %, короче шага, границы клипа.
- [ ] Тест `Editor::quantize_selection`: выбранные ноты против всех, один шаг
      отмены, точные тики/длины.
- [ ] Тест `Editor::set_note_velocity` и пропорционального масштабирования
      множественного выбора, зажим 1–127, один шаг отмены.
- [ ] Headless multi-frame тест на реальном `App`: перетаскивание полосы
      велосити меняет ноту, ноты подкрашиваются.
- [ ] Round-trip сохранения/загрузки сохраняет велосити.
- [ ] `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`,
      `cargo test --workspace --all-targets` зелёные.

## Вне области

Импорт `.mid`, выбор инструмента, изменение длины ноты мышью в сетке,
автоматизация велосити, кривые велосити, сохранение настроек квантизации в
проекте.
