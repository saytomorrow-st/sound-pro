# SPEC-036: Оформление окна в стиле студийной DAW

## Цель

Сделать окно аккуратным и похожим на привычную студийную программу.
Всё, что ещё не работает, показывать серыми неактивными кнопками с подсказкой «Скоро».

## Требования

1. **Палитра.** Дорожка без цвета получает цвет по номеру из 8 ярких цветов
   (`layout::display_color`).
2. **Регионы.** Тёмная полоса заголовка с именем, тело цвета дорожки, ноты и волна
   тёмным оттенком (`layout::region_colors`, `layout::shade`). У заглушённой дорожки
   регионы серые.
3. **Тулбар.** Слева кнопки панелей. По центру транспорт ⏮ ⏪ ⏩ ⏹ ▶ ⏺ (⏪ и ⏩ — заглушки),
   скруглённый экран позиции и режимы. Справа кнопки браузера и заглушки.
4. **Заголовки дорожек.** Цветная иконка (♪ — MIDI, 〰 — аудио), имя, скруглённые
   кнопки M/S (работают) и R/I (заглушки), компактные регуляторы громкости и панорамы.
5. **Стрип канала** нарисован вручную:
   - заглушки Settings, EQ и MIDI FX;
   - рабочие слоты Audio FX и Sends;
   - ручка панорамы: перетаскивание меняет pan, угол — `layout::pan_angle` (радианы),
     двойной щелчок ставит центр;
   - фейдер в шкале dB (`layout::fader_position` / `fader_gain`, низ — −60 dB),
     двойной щелчок ставит 0 dB, рядом декоративный индикатор;
   - кнопки M/S и цветная плашка с именем.
6. **Инспектор.** Два стрипа рядом: выбранная дорожка и Stereo Out.
   **Микшер** использует те же стрипы.
7. При активной автоматизации ручка и фейдер не реагируют.

## Граничные случаи

- `fader_position(0)` = 0, `fader_position(1)` = 1 (0 dB вверху), −6 dB ≈ 0.9; NaN даёт 0.
- `fader_gain(fader_position(g)) ≈ g` для g от −60 dB до 0 dB.
- `pan_angle` ограничен ±135°, NaN даёт 0.
- `shade` с NaN не меняет цвет.

## Проверка

- Юнит-тесты в `crates/daw-gui/tests/layout.rs`.
- Пример `demo_project` и самоснимок окна через `SOUND_PRO_SCREENSHOT`
  для визуальной проверки.
