# SPEC-028: Шины и посылы

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Эффекты стоят только на самих дорожках. Чтобы дать нескольким дорожкам
общий реверб, его приходится ставить на каждую. В любой DAW для этого есть
шины (aux) и посылы: дорожка отправляет часть своего звука на шину, на шине
стоит один общий эффект.

## Поведение

### Модель (`audio_core::session`)

- `Session::buses: Vec<Bus>` — по умолчанию пусто, не больше `MAX_BUSES = 4`.
- `Bus { name, gain, effects }`; `Bus::new(name)` — `gain = 1`, без эффектов.
  Имя подчиняется тем же правилам, что имя дорожки; `gain` в `0 … 1`;
  эффекты — как у дорожки (SPEC-022, не больше 8).
- `Track::sends: Vec<BusSend>` — по умолчанию пусто, не больше `MAX_BUSES`.
  `BusSend { bus, level }`: индекс шины в `Session::buses`, уровень `0 … 1`.
  Одна шина — не больше одного посыла с дорожки.
- `Track::send_level(bus)` — уровень посыла или `0`, если посыла нет.
- `validate` отклоняет нарушения: `SessionError::InvalidBus { bus }`
  (для лишней шины `bus = MAX_BUSES`) и
  `SessionError::InvalidSend { track, send }` (лишний посыл, индекс шины вне
  списка, повтор шины, уровень вне диапазона).

### Звук

- Если шин нет — рендер бит-в-бит как раньше (goldens не меняются).
- Если шины есть, весь микс считает один узел `daw_app::nodes::Mixer`:
  1. каждая дорожка рендерится как раньше (клипы, эффекты, автоматизация,
     громкость, панорама, mute/solo), но без мастер-громкости;
  2. её стерео-выход идёт в микс, а выход × `level` — во вход шины
     (посыл после фейдера; заглушённая дорожка ничего не посылает);
  3. вход шины проходит её эффекты (по одному набору на канал), умножается
     на `gain` и прибавляется к миксу;
  4. мастер-громкость применяется один раз ко всей сумме.
- Узел не аллоцирует в `process`; буферы выделяются при построении.

### JSON (`audio_core::project`)

- У дорожки необязательный ключ `"sends": [{"bus": 0, "level": 0.5}]`,
  пишется только если посылы есть.
- У сессии необязательный ключ `"buses": [{"name": "Reverb", "gain": 1,
  "effects": [...]}]`, пишется только если шины есть. `gain` по умолчанию 1,
  `effects` по умолчанию пусто.
- Неизвестные ключи отклоняются; старые проекты читаются без изменений.

### Редактор (`daw_gui::Editor`)

- `add_bus`, `remove_bus`, `set_bus_gain`, `set_send(track, bus, level)`
  (`level = 0` убирает посыл), `add_bus_effect`, `remove_bus_effect`,
  `set_bus_effect`. Каждое действие — один шаг отмены.
- `remove_bus` удаляет посылы на эту шину со всех дорожек и сдвигает
  индексы посылов на шины после неё.

### Окно

- Кнопка «Шины» открывает окно: список шин с громкостью, кнопкой эффектов
  и удалением; кнопка «+ Шина» создаёт «Шина N» сразу с реверберацией
  (одно действие окна, два шага отмены).
- Окно эффектов общее для дорожек и шин; у шины нет перестановки эффектов.
- В том же окне для выбранной дорожки — ползунок посыла на каждую шину.

## Критерии приёмки

- [x] Без шин рендер и проекты бит-в-бит как раньше.
- [x] Посыл слышен: дорожка с посылом на шину с `gain = 1` даёт сигнал
      `dry + dry × level`.
- [x] Эффект на шине меняет звук только посланной части.
- [x] Мастер-громкость применяется один раз.
- [x] JSON: круговой проход шин и посылов, неверные данные отклоняются.
- [x] Editor: добавление/удаление шины с посылами и отмена.
