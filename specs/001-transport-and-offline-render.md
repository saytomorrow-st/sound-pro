# SPEC-001: Транспорт и offline-рендер

Статус: implemented
Владелец: команда движка
Для агента: разрешено реализовывать

## Проблема

Нужен минимальный вертикальный срез движка: часы, граф, WAV, offline-рендер —
достаточно, чтобы все дальнейшие функции (запись, плагины, UI) имели проверяемую
основу и работали в CI без звуковой карты.

## Поведение

1. **Транспорт.** Позиция — абсолютный номер сэмпла (`u64`). Позиция в тактах
   вычисляется из сэмплов, а не накапливается; `SeekSamples` назад/вперёд точен.
   При `Stop` позиция не меняется и выход — тишина.
2. **Граф.** Узлы выполняются в порядке добавления; их выходы суммируются.
   Ёмкость узлов и размер кванта резервируются при создании; сверх резерва —
   ошибка `CapacityExhausted` / `QuantumTooLarge`, а не аллокация.
3. **Рендер.** `Renderer::render` — единственный путь воспроизведения и для
   реального бэкенда, и для offline. `OfflineRenderer::bounce` рендерит быстрее
   реального времени и результат не зависит от размера кванта для процессоров,
   зависящих только от абсолютной позиции.
4. **WAV.** Чтение float32 и PCM16 (PCM16 масштабируется на `1/32768`), запись
   float32. Golden-файлы — 48 кГц, моно.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| `frames == 0` | `RenderError::InvalidFrameCount(0)` |
| `frames > max_quantum` | `InvalidFrameCount` (рендер) / `QuantumTooLarge` (граф) |
| `mix` с меньшим числом каналов | `ChannelOutOfRange`, без паники |
| `bounce(1000)` при блоке 128 | последний блок 104 сэмпла, длина ровно 1000 |
| `SetTempo(0.0)` | команда игнорируется |
| остановленный транспорт + генератор | тишина, позиция не растёт |
