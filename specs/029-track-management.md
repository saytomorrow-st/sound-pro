# SPEC-029: Управление дорожками

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Дорожки получают имя при создании, и его нельзя поменять. Все клипы одного
цвета, порядок дорожек не меняется, а чтобы повторить дорожку с теми же
эффектами, её приходится собирать заново.

## Поведение

### Модель (`audio_core::session`)

- `Track::color: Option<u8>` — номер цвета из палитры `TRACK_COLORS = 8`;
  `None` — цвет по умолчанию. `Track::new` даёт `None`.
- `validate` отклоняет `color >= TRACK_COLORS`:
  `SessionError::InvalidColor { track }`.
- Цвет не влияет на звук.

### JSON (`audio_core::project`)

- У дорожки необязательный ключ `"color": 3`, пишется только если цвет задан.
  Старые проекты читаются без изменений и записываются бит-в-бит как раньше.
- Не целое число или число вне `0 … 255` — `ProjectError`; число вне палитры —
  ошибка сессии.

### Редактор (`daw_gui::Editor`)

Каждое действие — один шаг отмены; при ошибке состояние не меняется.

- `rename_track(track, name)`: обрезает пробелы по краям; пустое имя —
  `EditorError::EmptyName`, слишком длинное — `EditorError::Session`.
  То же имя — ничего не делает (без шага отмены).
- `set_track_color(track, Option<u8>)`.
- `move_track(from, to)`: переносит дорожку на место `to`, остальные сдвигаются;
  выделение следует за перенесённой дорожкой, выделенный клип сбрасывается.
  `from == to` — ничего не делает.
- `duplicate_track(track) -> usize`: копия (клипы, эффекты, автоматизация,
  посылы, цвет) встаёт сразу под оригиналом с именем «<имя> копия» и
  становится выделенной. Больше `MAX_TRACKS` — `EditorError::Session`.
- Плохой индекс дорожки — `EditorError::NoClip`.

### Окно

- Двойной щелчок по имени дорожки — поле ввода; Enter или уход фокуса
  сохраняет, Esc отменяет.
- Правый щелчок по заголовку дорожки — меню: «Переименовать», цвета палитры
  и «Без цвета», «Выше», «Ниже», «Дублировать», «Удалить».
- Клипы и полоска слева в заголовке рисуются цветом дорожки.

## Граничные случаи

- Перенос/дублирование не ломают посылы: индексы шин не меняются.
- Открытые окна эффектов и автоматизации закрываются при переносе и
  дублировании, чтобы не показывать чужую дорожку.

## Критерии приёмки

- [x] Без цвета проект записывается бит-в-бит как раньше.
- [x] JSON: круговой проход цвета, неверный цвет отклоняется.
- [x] Editor: переименование, цвет, перенос, дублирование и отмена каждого.
- [x] Рендер не зависит от цвета и порядка дорожек.
