# SPEC-013: Микшер — панорама, solo, мастер, стерео-рендер

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Сессия (SPEC-010) умеет только gain и mute на дорожку и рендерит моно.
Нельзя развести дорожки по каналам, послушать одну дорожку отдельно (solo) и
сделать общую громкость микса.

## Поведение

### Модель (`audio_core::session`)

- `Track::pan: f32` — панорама в `[-1, 1]`: `-1` — только левый канал, `0` —
  центр, `1` — только правый. По умолчанию `0.0`.
- `Track::solo: bool` — по умолчанию `false`.
- `Session::master_gain: f32` — линейная громкость мастера в `[0, 1]`, по
  умолчанию `1.0`.
- `Session::validate` дополнительно проверяет: `master_gain` конечен и в
  `[0, 1]` (иначе `SessionError::InvalidMasterGain`); `pan` каждой дорожки
  конечен и в `[-1, 1]` (иначе `SessionError::InvalidPan { track }`).
  Порядок: master проверяется после темпа и до числа дорожек; pan — сразу
  после gain дорожки.
- `Session::is_audible(track) -> bool`: дорожка звучит, если она не `mute` и
  (ни одна дорожка сессии не `solo` или она сама `solo`). **Mute сильнее
  solo**: дорожка с `mute` и `solo` молчит, но включает режим solo для
  остальных. Индекс вне диапазона — `false`.

### Закон панорамы

Баланс с 0 дБ в центре:

```
left  = if pan <= 0 { 1 } else { 1 - pan }
right = if pan >= 0 { 1 } else { 1 + pan }
```

В центре оба множителя ровно `1.0`, поэтому сессия без панорамы звучит в
каждом канале **бит-в-бит** как прежний моно-рендер.

### Рендер

- `build_session_graph` строит граф на **2 канала**. Узел `nodes::Track`
  получает уже вычисленную слышимость (`mute || !is_audible`) и множители
  `left * master_gain`, `right * master_gain`.
- `Track::process`: моно-сумма клипов × gain дорожки, затем канал 0 ×
  левый множитель, канал 1 × правый. Если вид узла одноканальный, пишется
  только канал 0 с левым множителем (панорама игнорируется, мастер — нет).
- Мастер применяется к каждой дорожке до суммы; это линейно эквивалентно
  мастеру после суммы. С `master_gain == 1.0` результат не меняется.
- `render_session` пишет **стерео** float32 WAV (2 канала). `SessionReport`
  не меняется.
- На горячем пути по-прежнему нет аллокаций, блокировок и I/O: всё считается
  при построении узла.

### JSON

- Дорожка пишется в порядке `name, gain, pan, mute, solo, clips`.
- Сессия: `name, sample_rate, tempo_bpm, master_gain, tracks`.
- При чтении `pan`, `solo` и `master_gain` **необязательны** (умолчания выше):
  файлы, сохранённые до SPEC-013, открываются без изменений. `version`
  документа остаётся `1`.
- Неверный тип (`"solo": 1`, `"pan": "x"`) — `Malformed`. Значение вне
  диапазона — `ProjectError::Session(...)` через `validate`.

### CLI

- `daw session show` печатает `gain= pan= mute= solo= clips=` для дорожки и
  строку `master_gain=` перед `session_frames=`.
- Демо-сессия: `low` с `pan = -0.5`, `high` с `pan = 0.5`.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Ни одной solo-дорожки | звучат все не-mute |
| Две solo-дорожки | звучат обе, остальные молчат |
| Единственная solo-дорожка ещё и mute | тишина во всей сессии |
| `pan = -1` | правый канал — точные нули |
| `pan = 1` | левый канал — точные нули |
| `pan = 0`, `master = 1` | оба канала бит-в-бит равны прежнему моно |
| `master_gain = 0` | тишина в обоих каналах |
| `pan = 1.5`, `NaN` | `InvalidPan { track }` |
| `master_gain = 2`, `NaN` | `InvalidMasterGain` |
| старый JSON без новых полей | читается, pan 0, solo false, master 1 |

## Вне области

на дорожке, автоматизация, метры уровня, живое изменение микса во время
воспроизведения, UI микшера.

## Найденный дефект движка

Стерео-рендер вскрыл ошибку в `Graph::process`: на коротком (неполном)
кванте граф читал каналы узла с шагом полного буфера, хотя узел писал с шагом
`frames`. Канал 0 совпадал, канал 1 и далее сдвигались или терялись. В моно
это было незаметно. Исправлено: выход узла читается через тот же `NodeView`.
Регрессия: `a_short_quantum_keeps_every_channel_in_its_own_lane`
(`crates/audio-core/tests/render_quantum_tail.rs`).
