# SPEC-057: Перетаскивание дорожек и папок, групповой drop в папку

Статус: ready
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Дорожки и папки можно переупорядочивать только через контекстное меню
(«Выше» / «Ниже») по одной строке за раз. В Logic Pro порядок дорожек
меняют перетаскиванием заголовка, а несколько выделенных дорожек можно
бросить в папку одним движением. Здесь такого нет: нет drag reorder, нет
drop в папку, нет групповых действий над папками.

## Цель

Добавить drag-and-drop поверх существующей модели выделения и папок
(SPEC-047, SPEC-055): перетаскивание одной или группы дорожек меняет
порядок, drop на папку добавляет дорожки в неё, перетаскивание папки
перемещает её вместе с детьми. Всё — один шаг Undo, без изменения
аудио-пути и формата проекта.

## Поведение

### §1 Drag reorder (порядок дорожек)

- Перетаскивание заголовка дорожки (или любой дорожки из выделенной группы)
  меняет порядок дорожек. Индикатор вставки — горизонтальная линия между
  строками, под курсором.
- Перетаскивание использует `Editor::move_track` (TrackAction::Move) для
  одиночной дорожки и новый `Editor::move_tracks` для группы; оба — один шаг
  Undo. Новый параллельный путь не вводится.
- Группа дорожек перетаскивается целиком: относительный порядок внутри группы
  сохраняется, индексы папок (`folder_children`) и `track_heights`
  пересчитываются корректно.
- Порог начала drag ~4 px (клик без движения — не drag), не конфликтует с
  контекстным меню и ресайзом высоты (SPEC-056, `track_resize_handle`).

### §2 Drop в папку

- Drop заголовка дорожки (одной или всей выделенной группы) на заголовок
  папки или на строку внутри папки добавляет их в папку через новый
  `Editor::move_tracks_to_folder(folder, tracks)` одним шагом Undo.
- Дорожки, уже лежащие в другой папке, переносятся между папками (их
  удаляют из прежней и добавляют в целевую) — операция не ломается.
- Перетаскивание дорожки из папки наружу (на строку вне папки) убирает её
  из папки (`remove_tracks_from_folder`) одним шагом Undo.

### §3 Перетаскивание папки

- Перетаскивание папки целиком переупорядочивает её вместе с детьми через
  существующий `Editor::move_folder` (один шаг Undo).
- Drop папки внутрь папки не поддерживается (одноуровневая вложенность,
  SPEC-055 §7): такой drop игнорируется.

### §4 Мультивыделение папок

- Ctrl+клик по папке добавляет/убирает папку из выделения
  (`selected_folders()`); Shift+клик — диапазон. Простой клик — одиночное
  выделение, сбрасывает выделение дорожек.
- Выделение папок остаётся взаимоисключающим с выделением дорожек и клипов.
- Групповые действия по выделенным папкам там, где это тривиально:
  свернуть/развернуть, удалить (с тем же диалогом), цвет.

### §5 Ограничения drag

- Drag не срабатывает при клике без движения (порог ~4 px).
- Не конфликтует с контекстным меню, ресайзом высоты (SPEC-056) и drop
  аудиофайлов (`handle_drop` / `drop_target`, `tests/drop.rs`).

## Архитектурные ограничения

- Раскладка строк — `crates/daw-gui/src/track_rows.rs`; для hit-test по y
  использовать `row_at_y_heights` / `row_y`, не хардкодить высоты.
- Чистую логику «куда вставляется при drop по y» вынести в `track_rows.rs`
  в тестируемую функцию (номер строки вставки по y).
- Высоты хранятся в `App.track_heights`; при групповом перемещении
  синхронизировать высоты корректно (аналог `reindex_height_move` для
  множества).
- Realtime-путь, `audio-core`, формат проекта не трогать. Новых зависимостей
  нет.

## Вне области

- Marquee-выделение дорожек/папок.
- Вложенные папки (drop папки в папку).
- Групповая громкость/M/S папок.

## Тесты

- `crates/daw-gui/src/track_rows.rs` — чистая логика позиции вставки по y.
- `crates/daw-gui/tests/track_reorder.rs` — групповой move, group add to
  folder (включая перенос между папками), remove из папки, undo/redo,
  мультивыделение папок.
- Существующие тесты и CI зелёные; goldens не трогать.
