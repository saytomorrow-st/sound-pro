# SPEC-002: Запись WAV на диск с разбиением на части

Статус: ready
Владелец: команда движка
Для агента: разрешено реализовывать

Файлы: `crates/audio-core/src/{wav.rs,offline.rs}`, `crates/daw-app/src/lib.rs`,
`crates/daw-app/src/main.rs`, `crates/audio-core/tests/`, `docs/`

## Проблема

`daw bounce` пишет один файл целиком в память. Для длинных сессий
(30+ минут, 8 каналов) это гигабайты RAM, а при сбое весь рендер теряется.

## Поведение

1. Новый тип `Recorder` в `audio-core`: пишет сэмплы в WAV инкрементально,
   буфер фиксированного размера, выделенный в конструкторе.
2. `Recorder::new(path, spec, max_part_samples)` создаёт файл сразу; при
   достижении `max_part_samples` текущий файл закрывается и открывается
   следующий с суффиксом `-01`, `-02`… (`part-01.wav`, `part-02.wav`).
3. `Recorder::write(&[f32])` возвращает `Result`, ошибки — `WavError`.
4. `Recorder::finish()` дописывает корректный RIFF-заголовок с фактической
   длиной и возвращает `Vec<PathBuf>` записанных частей.
5. CLI: `daw bounce out.wav 60.0 --split 600` — часть каждые 10 секунд.
6. Явный запрет: `Recorder` не должен использоваться из `Graph::process`.
   В `docs/REALTIME.md` добавить абзац: запись идёт в fallback-потоке, данные
   приходят через SPSC-очередь (SPEC-003).

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| `max_part_samples == 0` | `WavError::Io` с понятным текстом (или новый вариант `InvalidPartSize`) |
| `write(&[])` | `Ok(())`, файл не меняется |
| `finish()` без единого `write` | валидный WAV длиной 0 сэмплов |
| запись поверх существующего файла | перезапись, без дозаписи в хвост |
| ошибка диска посреди сессии | `Err`, уже записанные части остаются на диске |
| путь в несуществующей папке | папка создаётся (как в `run_offline`) |

## Критерии приёмки

- [ ] Юнит-тесты на пункты 1–4, включая точное разбиение (граница части).
- [ ] Интеграционный тест: `bounce --split` даёт N файлов, сумма длин = запрошенной.
- [ ] Чтение каждой части через `read_wav_mono` даёт те же сэмплы, что и `bounce` без разбиения.
- [ ] `cargo clippy -- -D warnings` и `cargo test` зелёные.
- [ ] `docs/DEVSETUP.md`/`README.md` упоминают флаг `--split`.

## Вне области
