## Проблема

Сейчас единственный источник звука — встроенное пианино
(`piano::render_piano`, 30 mp3 `include_bytes!`) и ручной выбор локальной
SFZ-папки через инспектор (SPEC-065). Нет каталога свободных библиотек, нет
реестра установленных банков, атрибуция авторов зашита одной строкой
`PIANO_CREDIT` в окне «О программе». Нужно (1) завести в репозитории
версионированный каталог-манифест со ссылками на оригинальные URL и
закреплёнными SHA-256 (хостим **ничего** — решение владельца), (2) реестр
установленных банков в каталоге данных пользователя (локальная установка из
SFZ-папки с подтверждением лицензии для share-alike/GPL), (3) окно «Библиотека
звуков» со статусом банков, (4) окно «Авторы» с атрибуцией установленных
банков и встроенного пианино, (5) диалог первого запуска в духе Logic Pro.

## Поведение

### 1. Каталог-манифест (`catalog/banks/*.json`, `daw-app::bank_library`)

Каталог — это файлы-манифесты в репозитории, встраиваемые через
`include_str!` при сборке (внешнего сервера каталога нет). Формат
версионирован (`schema`), поля:

```json
{
  "schema": 1,
  "id": "salamander-grand-v3",
  "name": "Salamander Grand Piano V3",
  "family": "piano",
  "version": "3",
  "author": "Alexander Holm",
  "license": { "spdx": "CC-BY-3.0", "url": "https://creativecommons.org/licenses/by/3.0/",
               "attribution_required": true },
  "attribution": "Salamander Grand Piano by Alexander Holm, CC-BY 3.0",
  "source_url": "https://archive.org/details/SalamanderGrandPianoV3",
  "sha256": null,
  "size_bytes": null,
  "verified": false
}
```

Правила валидации (типизированные ошибки `CatalogError`):

- `schema` обязателен и равен поддерживаемому (`1`); иначе `UnsupportedSchema`.
- `id`, `name`, `family`, `version`, `author`, `source_url` — непустые;
  `license.spdx` — распознанный SPDX-id из разрешённого набора; `license.url`
  — непустой URL (для CC-BY обязателен).
- **Запрещённые лицензии**: NC, ND, «free for personal use»/без явной
  лицензии → `ForbiddenLicense` (жёсткая ошибка, банк не попадает в каталог).
- **CC-BY (3.0/4.0)**: `license.attribution_required` обязателен, а
  `attribution` (текст атрибуции) — непустой; без него `MissingAttribution`.
- **CC-BY-SA / GPL-подобные**: в каталог **не** включаются; допустимы только
  как локальный импорт с предупреждением (см. §2). Если такой `spdx` попал в
  манифест каталога — `ForbiddenLicense`.
- `sha256` — либо `null` (явный плейсхолдер: банк **не** скачиваем, пока
  SPEC-067 не заполнит хэш), либо 64 строчных hex-символа; иначе
  `BadHash`. `size_bytes` — `null` или неотрицательное целое.
- `verified` — булево: `true`, только если хэш/размер реально проверены
  владельцем. В этом PR все записи `verified: false`, `sha256: null`,
  `size_bytes: null` — **не выдумываем** хэши и размеры.

Парсер читает встроенный JSON (`include_str!`) и возвращает
`Vec<CatalogEntry>`; любая ошибка одного файла — `CatalogError` (каталог
собран неполным не молчаливо: строка и банк указаны в ошибке).

### 2. Менеджер библиотеки (реестр установленных банков)

`bank_library` хранит реестр установленных банков в каталоге данных
пользователя:

- Linux: `$XDG_DATA_HOME/sound-pro/banks/`, по умолчанию
  `~/.local/share/sound-pro/banks/`.
- Windows: `%LOCALAPPDATA%\sound-pro\banks\`.
- Реестр — файл `banks.json` рядом с папками банков; формат —
  `serde_json`, версия `schema: 1`, список записей `InstalledBank`:
  `{ id, name, family, path, license_spdx, attribution, installed_at }`
  (`installed_at` — строка ISO-8601).

Локальная установка — функция `install_local_bank(dir, bank_id, license)`:
копирует выбранную SFZ-папку в `banks/<bank_id>/` (или регистрирует путь —
см. граничные случаи) и добавляет запись в реестр. Для share-alike/GPL
(`CC-BY-SA-*`, `GPL-*`, `AGPL-*`, `LGPL-*`) вызывающая сторона обязана
сначала показать подтверждение лицензии (`license_acknowledged`), иначе
`LibraryError::LicenseNotAcknowledged` — жёсткая ошибка; CC0/Unlicense/
MIT/BSD/CC-BY не требуют подтверждения. `list_installed() -> Vec<InstalledBank>`
и `remove(bank_id)` удаляют папку и запись. Всё I/O — на контрольном
потоке, не в аудиоколбэке.

### 3. Окно «Библиотека звуков» (GUI)

Пункт меню «Справка» → «Библиотека звуков…» открывает окно со списком из
встроенного каталога (Salamander, Osiris Piano) и установленных банков.
Каждая строка: имя, автор, семейство, лицензия (SPDX), статус:

- `Не установлен` + кнопка «Скачать» — **заблокирована**/disabled с подписью
  «Скоро» (SPEC-067), потому что `sha256` — плейсхолдер; для банка с
  `sha256: null` кнопка всегда disabled.
- `Установлен` (есть в реестре) + кнопка «Удалить».
- «Установить из папки…» — `rfd::FileDialog::pick_folder`, затем
  `install_local_bank`; если выбранная папка имеет лицензию CC-BY-SA/GPL
  (определяется по реестру/вводу), показывается диалог подтверждения
  лицензии перед установкой.

### 4. Окно «Авторы» (Credits)

Заменяет текущее использование `PIANO_CREDIT` в окне «О программе». Новое
окно «Авторы» строится из атрибуций установленных банков (из реестра) **и**
встроенного пианино (текст — та же строка, что и `PIANO_CREDIT`), показывая
для каждой: название, автор, лицензия, ссылка (source_url/url), текст
атрибуции; для CC-BY — значок «атрибуция обязательна». Кнопка «Скопировать
авторов» кладёт готовый текст в буфер обмена (`egui` clipboard). Окно
открывается из «Справка» → «Авторы…» и из «О программе».

`PIANO_CREDIT` остаётся в `piano.rs` как единственный источник строки
встроенного пианино (не удаляется; текст генерируется функцией
`bank_library::credits_text`), но GUI больше не читает его напрямую — читает
собранный текст авторов.

### 5. Диалог первого запуска (как Logic Pro)

При первом запуске показывается модальный диалог: «Для инструментов нужны
звуки (≈ … МиБ). **Скачать звуки сейчас** / **Позже**». «Позже» ничего не
качает и запоминается в настройках (`first_run_done`), «Скачать звуки
сейчас» в этом PR ведёт к окну «Библиотека звуков» (скачивание — SPEC-067).
Диалог показывается один раз; повторно доступен из меню «Справка» →
«Библиотека звуков…». Флаг хранится в настройках рядом с `audio.conf`
(ключ `first_run_done` в том же `key = value`-формате либо отдельный файл
`settings.conf` в той же папке).

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| манифест с `schema: 2` | `CatalogError::UnsupportedSchema` |
| манифест с `spdx: "CC-BY-NC-4.0"` / «free for personal use» | `ForbiddenLicense` |
| CC-BY без `attribution` / `attribution_required: false` | `MissingAttribution` |
| `sha256` — 63 hex-символа или не-hex | `BadHash` |
| `sha256: null` (плейсхолдер) | банк не скачиваем, кнопка «Скачать» disabled |
| установка CC-BY-SA/GPL без подтверждения | `LicenseNotAcknowledged` |
| установка CC0/Unlicense/MIT/BSD/CC-BY | без подтверждения |
| удаление несуществующего банка | no-op / ошибка не фатальна |
| реестр повреждён / отсутствует | пустой список, загрузка не падает |
| старый файл настроек без `first_run_done` | диалог первого запуска показывается |
