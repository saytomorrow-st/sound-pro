# SPEC-045: Фейды: формы, правила, запись, окно

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Отзыв пользователя после v0.1.16:

- фейды бывают только линейными, форму нельзя поменять, как в Logic;
- под крестом кроссфейда пропадает волна;
- у региона с кроссфейдом можно потянуть из угла ещё один фейд — двойной фейд;
- после разрезания региона с кроссфейдом фейды «склеиваются» не по правилам;
- запись идёт, даже если R (готовность к записи) выключена;
- в полноэкранном режиме окно нельзя свернуть;
- переключатель темпа на дисплее не выровнен с соседними ячейками.

## Цель

Фейды с формой и чёткими правилами, видимая волна под кроссфейдом, запись
только на дорожку с R, рабочая кнопка «свернуть» в полноэкранном режиме.

## Критерии приёмки

### §1 Формы фейдов

`Clip` хранит `fade_in_curve` и `fade_out_curve` в `-1..=1` (0 — линейная).
Усиление на доле `x` фейда: `shape_fade(x, c) = x^(2^(-2c))`; при `c = 0`
ровно `x` (бит в бит прежнее поведение). `c > 0` — быстрое начало
(логарифмическая), `c < 0` — медленное (экспоненциальная). Кривая вне
диапазона или NaN — `SessionError::InvalidFadeCurve`. В JSON поля пишутся
только когда не 0; старые проекты читаются как линейные.

### §2 Правило смешивания

Явный фейд заменяет автоматический спад в зоне наложения: явный кроссфейд
(линейный) даёт постоянный уровень на всём наложении. Нижний клип, который
перекрыт более поздним, игнорирует свой фейд-аут в зоне перекрытия.

### §3 Правила разрезания

При разрезании каждая часть сохраняет только свой внешний фейд: левая — фейд-ин,
правая — фейд-аут; внутренние фейды и их формы сбрасываются. Кроссфейд с
соседом при разрезании не меняется.

### §4 Запись только с R

Кнопка записи ничего не пишет, если ни на одной дорожке не включена R;
статус: «Включите R (готовность к записи) на дорожке».

### §5 Нет ручки фейда внутри наложения

Край клипа, лежащий внутри другого клипа той же дорожки, принадлежит
кроссфейду: на нём нет угловой ручки, его нельзя тянуть ни указателем, ни
инструментом «Фейд» (`layout::edges_in_overlap`). Касание — не наложение.

### §6 Волна видна под кроссфейдом

Зона наложения полупрозрачна; волны всех клипов под ней рисуются поверх, а
тонкий крест — над волнами.

### §7 Свернуть в полноэкранном режиме

Кнопка 🗕 сначала выходит из полноэкранного режима, затем сворачивает окно.

### §8 Выравнивание темпа

Поле темпа на дисплее — того же шрифта и высоты, что соседние значения, без
рамки кнопки.

### §9 Форма фейда в инспекторе

В инспекторе региона для каждого фейда — значение формы и пресеты «линейная»,
«экспоненциальная», «логарифмическая». Изменение — один шаг отмены; без
изменений шаг не добавляется.

## Граничные случаи

- Кривая NaN в редакторе считается линейной; вне диапазона — зажимается.
- Фейд нулевой длины не рисуется, его форма не влияет на звук.
- Клип нулевой длины не считается накрывающим.
