# SPEC-052: Экспорт микса с мастер-цепочкой и нормализацией

Статус: ready
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

SPEC-010/SPEC-035 уже дали офлайн-сведение через `daw_app::render_session` и
пункт меню «Экспорт сведения…» в `daw-gui`: микс пишется в один файл
`mixdown.wav` как 32-битный float-стерео на частоте сессии. Пользователю
нужно выбирать формат (16/24 бит), частоту дискретизации и опциональную
нормализацию по пику, а сам экспорт должен идти в фоне с прогрессом, не
блокируя окно. Рендер обязан проходить тем же офлайн-путём, что и `bounce`,
и учитывать шины, посылы и мастер-цепочку (SPEC-028, SPEC-051).

## Поведение

### Параметры экспорта (`daw_app`)

- `ExportSpec` — описание одного экспорта:
  - `bit_depth: BitDepth` — `I16` (16 бит) или `I24` (24 бита);
  - `sample_rate: u32` — целевая частота дискретизации;
  - `normalize: Option<f32>` — целевой пик в dBFS (`None` — без
    нормализации; `Some(db)` — пик приводится к `10^(db/20)`).
- Частоты берутся из допустимого набора (см. GUI); движок не накладывает
  ограничений, кроме `sample_rate > 0`.

### Рендер и запись (`daw_app`)

- Новый путь `render_export(job: SessionJob, spec: ExportSpec)` **переиспользует**
  существующие `build_session_graph` + `OfflineRenderer::bounce` и не
  дублирует сборку графа или сведение: сессия рендерится на её собственной
  частоте как раньше, затем:
  1. стерео-микс (каналы `AudioBuffer`) ресемплируется на `spec.sample_rate`
     через `audio_core::resample::resample` (для `from == to` — точная
     копия);
  2. если задана нормализация, вычисляется пик по обоим каналам; если пик
     равен нулю, файл пишется как есть (тишина не «взрывается» на `-inf`);
     иначе весь микс домножается на `target / peak`;
  3. микс пишется в WAV с выбранной разрядностью:
     - `I16` — `SampleFormat::Int`, `bits_per_sample = 16`, сэмпл
       `round(clamp(x, -1, 1) * 32767)`;
     - `I24` — `SampleFormat::Int`, `bits_per_sample = 24`, сэмпл
       `round(clamp(x, -1, 1) * 8388607)`.
- Возвращается `SessionReport` (та же структура, что у `render_session`), с
  `frames` — числом кадров на **целевой** частоте.
- `render_session` остаётся без изменений и продолжает писать 32-битный
  float-стерео на частоте сессии; `render_export` — тонкая надстройка.

### Запись WAV (`audio_core::wav`)

- `write_wav_pcm<P: AsRef<Path>>(path, sample_rate, channels, bits, samples:
  &[Sample])` — пишет целочисленный PCM-стерео с разрядностью 16 или 24.
  Поддержка 24 бит — через `hound` (`bits_per_sample = 24`).
- Существующие `write_wav_mono` (float-32) и `write_mono_slice` не меняются.

### Редактор (`daw_gui::Editor`)

- `export_with(&self, out: &Path, spec: &daw_app::ExportSpec) ->
  Result<daw_app::SessionReport, EditorError>` — как `export`, но с параметрами
  экспорта; `export` остаётся и делегирует на экспорт по умолчанию (32 бита
  float, частота сессии, без нормализации) для совместимости с тестами.
- Валидация пустого проекта (`Empty`) сохраняется.

### Окно (`daw_gui::main`)

- Пункт меню «Экспорт…» (`File → Export…`) открывает диалог экспорта вместо
  мгновенного «Экспорт сведения…». Диалог:
  - выбор файла через `rfd::FileDialog` (фильтр WAV, имя `mixdown.wav`);
  - выбор разрядности 16/24;
  - выбор частоты дискретизации (48 000 / 44 100 / 96 000 / 88 200);
  - флажок нормализации и поле целевого пика в dBFS (по умолчанию −1.0);
  - кнопка «Экспорт», запускающая фоновый поток.
- Экспорт идёт в фоновом потоке (`std::thread::spawn` + `std::sync::mpsc`),
  UI раз в кадр опрашивает канал и показывает индикатор прогресса (спиннер),
  пока идёт рендер; окно не блокируется. Результат (успех/ошибка) выводится
  в `status`.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Пустой проект | `EditorError::Empty`, файл не пишется |
| Тишина + нормализация | пик 0 → файл пишется как есть, без деления на 0 |
| `from == to` ресемпл | точная копия, без изменения сэмплов |
| Частота `0` | ошибка (`ResampleError::ZeroRate`) |
| 16 бит | значения в `[-32768, 32767]`, клиппинг вне `[-1, 1]` |
| 24 бит | значения в `[-8388608, 8388607]`, клиппинг вне `[-1, 1]` |
| Нормализация выше пика | усиление > 1 (не ограничивается) |
| Нормализация ниже пика | ослабление (не клиппинг) |
| Без нормализации | микс пишется бит-в-бит после ресемпла/разрядности |

## Критерии приёмки

- [ ] Юнит-тесты `wav`: `write_wav_pcm` для 16 и 24 бит, чтение обратно и
      проверка округления/клиппинга.
- [ ] Тесты `daw_app`: `render_export` пишет файл нужной разрядности и
      частоты; нормализация приводит пик к целевому dBFS; длина соответствует
      целевой частоте; результат без нормализации совпадает с `render_session`
      (при равной частоте и float) и с офлайн-рендером `bounce`.
- [ ] Тест тишины: нормализация не делит на ноль.
- [ ] `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D
      warnings`, `cargo test --workspace --all-targets` зелёные (включая
      windows-ветки `cfg(target_os)`).
- [ ] Golden-файлы не меняются.

## Вне области

- Нормализация по LUFS и анализ громкости (будущая спецификация).
- Экспорт MP3/FLAC/OGG.
- Экспорт отдельных шин/стемов.
- Изменение частоты сессии или ресемплинг исходных клипов до рендера
  (ресемплится только мастер-выход).
