# SPEC-070: Целостность PCM-кэша банка (Integrity L0–L3)

Статус: ready
Владелец: saytomorrow-st
Для агента: разрешено реализовывать

## Проблема

Кэш `cache/*.pcm` + `cache/manifest.json` (RFC-002 §5) — производные данные.
Повреждённый или неполный кэш молча отдаёт битый звук либо падение при
загрузке. При каждой загрузке инструмента нужно проверять целостность кэша,
карантинить и автоматически пересобирать повреждённые/недостающие файлы.

## Поведение

Реализуется в `crates/daw-app/src/bank_integrity.rs` (новый модуль).

- `IntegrityLevel` — перечисление уровней проверки `L0`, `L1`, `L2`, `L3`.
- `verify_bank_cache(dir, level, cancel) -> Result<IntegrityReport, String>`
  проверяет кэш банка и возвращает отчёт.
- **L0** (всегда, синхронно): прочитать манифест; проверить `format_version`;
  для каждой записи — файл существует, размер `== 64 + frames×channels×2`,
  заголовок `.pcm` (magic, version, CRC-32 по байтам 0..40, sample_rate,
  channels, frames) совпадает с манифестом.
- **L1** (фоном): mtime исходника и выборочный хэш xxh3-64 первых 64 KiB,
  последних 64 KiB и среднего блока 64 KiB `.pcm`.
- **L2** (фоном, раз за сессию и после аварийного завершения по маркеру
  `cache/.dirty`): полный xxh3-128 каждого `.pcm`.
- **L3** (по требованию / после сбоя): blake3 `.pcm` + xxh3-64 исходного FLAC.
- При несоответствии запись попадает в `issues` отчёта; файл карантинится
  (переименовывается в `*.quarantined`), пишется `log_warn!` (банк, файл,
  причина, ожидаемое/фактическое).
- `recover_bank_cache(dir, report, progress, cancel)` декодирует исходные
  FLAC повреждённых записей в `.pcm` (`.tmp` → rename) и обновляет манифест.
  Если исходного FLAC нет или его xxh3 не сходится — запись помечается
  `unrecoverable` с рекомендацией «скачать банк заново».

Проверка и восстановление идут только на control/loader-потоках, никогда в
audio-потоке.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Манифест отсутствует | `verify` возвращает ошибку «нет кэша» (кэш не собран) |
| `format_version` не совпал | весь кэш недоверенный, ошибка (нужна пересборка) |
| Файл меньше ожидаемого размера | issue `SizeMismatch`, карантин |
| Заголовок повреждён (CRC) | issue `BadHeader`, карантин |
| Данные повреждены, но заголовок цел | L1/L2 ловит по хэшу, карантин |
| Исходный FLAC отсутствует | `unrecoverable`, без попытки декодирования |
| Исходный FLAC изменился (mtime/xxh3) | карантин + пересборка из FLAC |
| `cancel` взведён | проверка прерывается на ближайшей границе |

## Критерии приёмки

- [ ] Юнит/интеграционные тесты: повреждённый файл, недостающий файл, неверный
      размер, испорченный заголовок, пересборка из FLAC, `unrecoverable`.
- [ ] `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`,
      `cargo test --workspace --all-targets` зелёные.
- [ ] Тесты не требуют аудиоустройства (offline, только файловый I/O).
