# SPEC-030: Маркеры

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

В длинной песне трудно найти нужное место: на линейке видны только номера
тактов. Нужны именованные метки («Куплет», «Припев») и быстрый переход к ним.

## Поведение

### Модель (`audio_core::session`)

- `Marker { name: String, position: u64 }` — позиция в сэмплах проекта.
- `Session::markers: Vec<Marker>`, отсортированы по позиции; `Session::new`
  даёт пустой список. `MAX_MARKERS = 256`.
- `validate` отклоняет: больше `MAX_MARKERS`, имя длиннее `MAX_NAME_BYTES`,
  нарушен порядок или две метки на одной позиции —
  `SessionError::InvalidMarker { marker }` (для «слишком много» —
  `marker = MAX_MARKERS`).
- Маркеры не влияют на звук.

### JSON (`audio_core::project`)

- Необязательный ключ сессии `"markers": [{"name": "Куплет", "position": 0}]`,
  пишется только если список не пуст. Старые проекты читаются и пишутся
  бит-в-бит как раньше.
- Нет `name` или `position` — `MissingField`; лишний ключ — `UnknownField`;
  не целая позиция — `Malformed`. Слишком длинный массив отклоняется ещё при
  разборе (`InvalidMarker { marker: MAX_MARKERS }`).

### Редактор (`daw_gui::Editor`)

Каждое изменение — один шаг отмены; при ошибке состояние не меняется.

- `add_marker(position) -> usize`: метка «Маркер N» (N — первый свободный
  номер от 1) встаёт по порядку; возвращает её индекс. Метка на занятой
  позиции — `EditorError::MarkerExists`; больше `MAX_MARKERS` —
  `EditorError::Session`.
- `rename_marker(index, name)`: как у дорожек — обрезка пробелов, пустое —
  `EmptyName`, то же имя — без шага отмены.
- `move_marker(index, position) -> usize`: переносит и пересортировывает,
  возвращает новый индекс; занятая позиция — `MarkerExists`.
- `delete_marker(index)`.
- `next_marker(position) -> Option<u64>`: первая метка строго правее;
  `previous_marker(position) -> Option<u64>`: последняя строго левее.
- Плохой индекс — `EditorError::NoMarker`.

### Окно

- Метки рисуются флажком с именем в нижней половине линейки и тонкой линией
  через дорожки.
- Клавиша `M` или кнопка «+ Маркер» — метка в позиции курсора.
- Щелчок по флажку — курсор к метке; перетаскивание флажка — перенос
  (с привязкой к долям, Shift — без привязки).
- Правый щелчок по флажку — «Переименовать» (поле ввода: Enter/уход фокуса
  сохраняет, Esc отменяет) и «Удалить».
- `,` и `.` — к предыдущей и следующей метке.

## Граничные случаи

- Метка за концом песни допустима.
- Перенос метки на её же позицию ничего не меняет.

## Критерии приёмки

- [x] Без маркеров проект записывается бит-в-бит как раньше.
- [x] JSON: круговой проход, ошибки разбора и проверки.
- [x] Editor: добавление, переименование, перенос, удаление, навигация, отмена.
- [x] Рендер не зависит от маркеров.
