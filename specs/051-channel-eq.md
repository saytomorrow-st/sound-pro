# SPEC-051: Channel EQ (8-полосный параметрический эквалайзер)

Статус: draft
Владелец: человек
Для агента: разрешено реализовывать

## Проблема

В движке есть только простой трёхполосный эквалайзер (`EffectKind::Eq`:
low shelf на 200 Гц, один пик с Q = 1, high shelf на 5000 Гц). Для клона
Logic Pro этого недостаточно: штатный канальный эквалайзер там
восьмиполосный и позволяет независимо ставить частоту, усиление и
добротность. Текущий `Eq` не даёт ни управлять добротностью, ни резать
низ/верх фильтрами.

## Поведение

Добавляется новый тип эффекта `EffectKind::ChannelEq` — восемь полос в
фиксированном порядке, форма каждой полосы определяется её индексом:

| № | Форма        | Параметры полосы            |
|---|--------------|-----------------------------|
| 0 | HP (high-pass, 12 дБ/окт) | `hz`            |
| 1 | Low shelf    | `hz`, `db`                  |
| 2 | Peak         | `hz`, `db`, `q`             |
| 3 | Peak         | `hz`, `db`, `q`             |
| 4 | Peak         | `hz`, `db`, `q`             |
| 5 | Peak         | `hz`, `db`, `q`             |
| 6 | High shelf   | `hz`, `db`                  |
| 7 | LP (low-pass, 12 дБ/окт)  | `hz`            |

Каждая полоса описывается структурой `ChannelEqBand { enabled, hz, db, q }`:

- `enabled: bool` — включена ли полоса. Выключенная полоса пропускает звук
  без изменений и не тратит состояние фильтра.
- `hz: f32` — частота, Гц, общий диапазон `20..=20000`.
- `db: f32` — усиление, дБ, `-24..=24`. Имеет смысл только для полос с
  усилением (1, 2–5, 6); для фильтров 0 и 7 игнорируется.
- `q: f32` — добротность, `0.1..=18`. Имеет смысл только для пиковых полос
  2–5; для остальных игнорируется.

Фильтры 0 и 7 — второпорядковые (12 дБ/окт) с добротностью Баттерворта
`1/√2`. Полки используют ту же формулу Бристоу-Джонсона с `S = 1`, что и
трёхполосный `Eq`. Пиковые полосы используют обобщённую формулу с
`α = sin w0 / (2·q)`.

Все восемь биквадов включены последовательно в порядке возрастания индекса.
`EffectProcessor::process` обрабатывает блок моно на месте, не аллоцируя, не
блокируя и не паникуя.

### Параметры по умолчанию

`EffectKind::channel_eq()` — плоская характеристика, звук проходит бит-точно:

- Полоса 0 (HP): выключена, `hz = 20`.
- Полоса 1 (low shelf): включена, `hz = 100`, `db = 0`.
- Полосы 2–5 (пики): включены, `hz = 300, 1000, 3000, 8000`, `db = 0`, `q = 1`.
- Полоса 6 (high shelf): включена, `hz = 10000`, `db = 0`.
- Полоса 7 (LP): выключена, `hz = 20000`.

Полоса с усилением активна, только когда `enabled && db != 0`; полоса-фильтр
активна, только когда `enabled`. Поэтому эквалайзер по умолчанию полностью
прозрачен и побитово равен входу.

### Сериализация

В проектных файлах тип называется `"channel_eq"`. Каждая полоса пишется
отдельными ключами:

```
"hp_on", "hp_hz",
"low_on", "low_hz", "low_shelf_db",
"p1_on", "p1_hz", "p1_db", "p1_q",
"p2_on", "p2_hz", "p2_db", "p2_q",
"p3_on", "p3_hz", "p3_db", "p3_q",
"p4_on", "p4_hz", "p4_db", "p4_q",
"high_on", "high_hz", "high_shelf_db",
"lp_on", "lp_hz"
```

`*_on` — булевы, остальные — числа. При чтении неизвестный ключ, отсутствующий
ключ или значение неверного типа дают `ProjectError`.

### Автоматизация

Непрерывные параметры добавляются в `EffectParam` (18 штук: `HpHz`, `LowHz`,
`LowShelfDb`, `P1Hz`, `P1Db`, `P1Q`, …, `HighHz`, `HighShelfDb`, `LpHz`; у
полос 0 и 7 усиления нет, но частота есть). Имена в файле совпадают с ключами
сериализации без суффикса `_on`. Дискретный флаг `enabled` не автоматизируется.
`EffectParam::ALL` расширяется до 30 элементов; диапазоны `range()` совпадают с
`is_valid`.

Ключи `low_shelf_db`/`high_shelf_db` и варианты `LowShelfDb`/`HighShelfDb`
вместо `low_db`/`high_db`: имена параметров обязаны быть уникальными между
типами эффектов, а `low_db` и `high_db` уже заняты трёхполосным `Eq`.

### GUI

В окне эффектов появляется кнопка «+ Канальный эквалайзер», заголовок
«Канальный эквалайзер» и слайдеры всех 18 непрерывных параметров. Полосы
отображаются в порядке возрастания индекса.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Все полосы выключены / усиления по 0 | бит-точно равный вход |
| `bypass = true` | бит-точно равный вход |
| `hz` у границы 20 или 20000 | принимается; биквад клеится к `0.45·Fs` при низкой частоте дискретизации |
| `hz > 0.45·Fs` (низкая частота дискретизации) | частота прижимается к `0.45·Fs`, фильтр устойчив |
| `q` на границе `0.1` или `18` | принимается |
| `db` на границе `±24` | принимается |
| `NaN`, бесконечность или выход за диапазон | `is_valid == false`, сессия не проходит `validate` |
| `update` с другим типом эффекта | состояние не меняется |
| `update` обратно в плоский | следующие блоки бит-точно равны входу |

## Критерии приёмки

- [ ] Юнит-тесты на каждое утверждение раздела «Поведение».
- [ ] Плоский `channel_eq` побитово прозрачен на синусе и тишине.
- [ ] Полосы реально режут/усиливают свои частоты (срезы и подъёмы в ожидаемых
      пределах).
- [ ] Фильтры 0/7 ослабляют соответственно низ и верх.
- [ ] Низкие частоты дискретизации остаются устойчивыми.
- [ ] `update` сохраняет состояние и совпадает со свежим процессором на тишине.
- [ ] `EffectParam` для `channel_eq`: имена ходят по кругу, `range` совпадает с
      `is_valid`, `get`/`set` работают.
- [ ] Сериализация `"channel_eq"` ходит по кругу; неизвестный/пропущенный ключ
      отвергается.
- [ ] Горячий путь не аллоцирует с цепочкой, включающей `channel_eq`.
- [ ] `cargo fmt`, `cargo clippy -- -D warnings`, `cargo test` зелёные.

## Вне области

- Графический редактор кривой АЧХ (только слайдеры).
- Автоматизация флага `enabled` полосы.
- Полосы выше 8 и другие формы (bell с переменной крутизной, notch, band-pass).
- Аналоговые эмуляции и фазовые режимы.
