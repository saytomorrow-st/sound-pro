# SPEC-050: Окно в полноэкранном режиме, предпросмотр дропа, микшер инспектора, стерео/моно

Статус: implemented
Владелец: saytomorrow

## Проблема

Отзыв после v0.1.21:
1. В полноэкранном режиме нет нормальных кнопок окна; если потянуть за верхний
   край, окно не выходит из полноэкранного режима и не двигается.
2. При перетаскивании файла из папки создаётся дорожка, а файл ставится с нуля;
   не видно, где и какой длины окажется регион.
3. Микшер в инспекторе кривой: полосы сдвинуты и не по сетке.
4. Дорожки можно создавать кликом по таймлайну, а должны — на панели дорожек.
5. Нет стерео- и моно-дорожек, как в Logic.
6. MP3 импортируется долго: файл целиком декодируется и пересэмплируется.

## Критерии приёмки

### §1 Окно
В полноэкранном режиме в панели управления есть кнопки «Свернуть», «Выйти из
полноэкранного режима», «Закрыть», и они работают. Нажатие и перетаскивание в
верхней полосе панели управления (вне кнопок) выводит окно из полноэкранного
режима и начинает перемещение окна системой.

### §2 Предпросмотр дропа
Пока файл над таймлайном, длина файла читается из заголовка без полного
декодирования. Рисуется рамка будущего региона: начало — под курсором (с
привязкой к сетке, как у регионов), ширина — по длине файла, строка — целевая
дорожка или «новая дорожка» ниже последней. Если длина неизвестна, остаётся
прежняя подсветка строки. Отпускание ставит регион ровно туда, где была рамка.

### §3 Микшер инспектора
Полоса дорожки и полоса выхода/шины одинаковой высоты, выровнены по верху, не
выходят за ширину инспектора.

### §4 Создание дорожек
Пустое место таймлайна не создаёт дорожку. Создание — кнопкой и контекстным
меню панели заголовков дорожек и через меню «Дорожка». Дроп файла ниже
последней дорожки по-прежнему создаёт новую.

### §5 Стерео/моно
У аудиодорожки есть формат «моно»/«стерео» (кнопка в заголовке, инспекторе и
диалоге «Новая дорожка»). Сохраняется в проекте; старые проекты — моно.
Стерео-регион хранит два канала, рисует две волны; моно-дорожка микширует
стерео в моно, стерео-дорожка дублирует моно в оба канала. Панорама моно —
pan, стерео — баланс.

### §6 Импорт MP3
Длина известна до декодирования (§2). Декодирование и пересэмплирование не
повторяются для уже загруженного файла. Импорт показывает прогресс.

## Граничные случаи
- Файл с частотой проекта не пересэмплируется.
- Повреждённый файл: ошибка в строке статуса, рамка не рисуется.
