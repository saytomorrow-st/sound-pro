## Проблема

Клип в сессии описывает только окно (`start`, `length`, `offset`,
`source_length`), но не говорит, откуда брать звук. Поэтому `daw render-session`
умеет сводить только встроенное демо, а сохранённый проект свести нельзя.

## Поведение

### Модель и JSON (audio-core)

- У `Clip` появляется поле `source: Option<String>` — путь к WAV-файлу.
- В JSON это необязательный ключ `"source"`, пишется последним в клипе и только
  если путь задан. Документы без ключа читаются как раньше (`source = None`),
  и их JSON после сохранения не меняется ни на байт.
- `Session::validate` отклоняет путь, который пуст или длиннее
  `MAX_SOURCE_BYTES = 4096` байт: `SessionError::InvalidSource { track, clip }`.
  Проверка идёт после имени клипа и до gain.
- audio-core путь не открывает и не трактует: это просто строка.

### Загрузка (daw-app)

`daw_app::load_session_project(path, output) -> Result<SessionJob, LoadError>`:

1. читает файл проекта и разбирает его `Project::from_json`;
2. для каждого клипа по порядку:
   - нет `source` → `LoadError::MissingSource { track, clip }`;
   - относительный путь считается от каталога файла проекта, абсолютный — как есть;
   - WAV читается `read_wav_mono`; ошибка → `LoadError::Wav { path, .. }`;
   - частота файла ≠ `session.sample_rate` → `LoadError::SampleRate { path, file, session }`;
   - кадров в файле меньше `source_length` → `LoadError::SourceTooShort { path, file_frames, source_length }`;
   - многоканальный файл сводится в моно средним по каналам (моно-файл
     берётся бит-в-бит); лишние кадры сверх `source_length` отбрасываются;
3. возвращает `SessionJob` с частотой сессии и `frames: None`.

Всё чтение — до старта рендера. Горячий путь не меняется: клип по-прежнему
`Vec<f32>` в памяти.

### CLI

`daw session render <project.json> <out.wav> [--seconds S]` — грузит проект и
сводит его в стерео WAV, как `render-session`. Ошибка загрузки → код 1 и
сообщение с путём.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Документ без `source` | читается, `source == None`, JSON не меняется |
| `"source": ""` | `Session(InvalidSource)` |
| `"source": 5` | `Malformed` |
| Файл не найден | `LoadError::Wav` с путём |
| Частота 44100 при сессии 48000 | `LoadError::SampleRate` |
| Файл короче `source_length` | `LoadError::SourceTooShort` |
| Файл длиннее | хвост отбрасывается |
| Стерео-файл | среднее по каналам |
| Два клипа на один файл | файл читается для каждого клипа отдельно |

## Критерии приёмки

- [x] Round-trip `source` и порядок ключей; старый документ без ключа.
- [x] `InvalidSource` для пустого и слишком длинного пути.
- [x] Интеграция: WAV во временном каталоге → проект с относительным путём →
      `load_session_project` → рендер бит-в-бит равен рендеру тех же сэмплов
      из памяти.
- [x] Ошибки: нет файла, не та частота, файл короче, нет `source`.
- [x] Стерео-файл сводится средним.
- [x] fmt, clippy, test зелёные; goldens не тронуты.
- [x] `docs/SESSION.md` и README обновлены.
