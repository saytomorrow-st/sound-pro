# SPEC-023: Автоматизация громкости и панорамы

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Громкость и панорама дорожки постоянны на всю песню. Нельзя плавно
вывести вступление, приглушить дорожку в куплете или провести звук слева
направо. В любой DAW для этого рисуют линию автоматизации поверх дорожки.

## Поведение

### Модель (`audio_core::session`)

- `Track::automation: Automation` — по умолчанию пустая.
- `Automation { gain: Vec<AutoPoint>, pan: Vec<AutoPoint> }`,
  `AutoPoint { time: u64, value: f32 }` — `time` в сэмплах таймлайна.
- `Lane { Gain, Pan }`; `Automation::lane(Lane)` / `lane_mut(Lane)`.
- Значение линии в момент `t` (`Automation::value_at(points, t)`):
  - пустая линия — `None` (действует обычное значение дорожки);
  - до первой точки — значение первой, после последней — значение
    последней;
  - между точками — линейная интерполяция.
- Непустая линия **заменяет** ползунок дорожки (`gain` или `pan`), как
  режим чтения автоматизации в DAW.
- Проверка (`Session::validate`, после эффектов дорожки) —
  `SessionError::InvalidAutomation { track, lane, point }`:
  - больше `MAX_AUTOMATION_POINTS = 1024` точек в линии
    (`point = MAX_AUTOMATION_POINTS`);
  - время точки не строго больше предыдущей;
  - значение не конечно или вне диапазона: громкость `0 … 1`,
    панорама `−1 … 1`.
- `pan_law(pan) -> (left, right)` — общий закон баланса из SPEC-013;
  `Track::pan_gains` использует его.

### Рендер (`daw_app::nodes::Track`)

- `with_automation(&Automation)` копирует точки при построении узла.
- Если обе линии пусты — путь обработки прежний, звук **бит-в-бит** как до
  SPEC-023, goldens не меняются.
- Иначе для каждого сэмпла `g = gain(pos)`, `(l, r) = pan_law(pan(pos))`,
  выход: правый = моно·g·r·master, левый = моно·g·l·master.
- Пустая линия громкости при `gain = 0` по-прежнему даёт тишину; mute
  всегда тишина.
- Без аллокаций, блокировок и паник на аудиопути.
- Правки слышны после следующего Play (как в SPEC-016). Экспорт микса
  учитывает автоматизацию.

### JSON

- У дорожки после `effects` пишется
  `"automation": {"gain": [{"time": 0, "value": 1}, ...], "pan": [...]}` —
  **только если хотя бы одна линия не пуста**; пустая линия не пишется.
- При чтении `automation` и обе линии необязательны. Старые файлы
  открываются как есть, `version` остаётся `1`.
- Неизвестный ключ, нехватка `time`/`value`, неверный тип — ошибки, как для
  клипов. Слишком длинная линия отвергается до разбора точек.

### Редактор (`daw_gui::Editor`)

- `add_point(track, lane, AutoPoint) -> Result<usize, EditorError>` —
  вставляет по времени; точка с тем же временем заменяется. Возвращает
  индекс.
- `move_point(track, lane, index, AutoPoint)` — время зажимается между
  соседями (порядок точек не меняется). Та же точка — без шага отмены.
- `remove_point(track, lane, index)`, `clear_lane(track, lane)`.
- Всё через проверку сессии и с отменой. Нет дорожки или точки —
  `EditorError::NoPoint`; значение вне диапазона —
  `EditorError::Session(InvalidAutomation)`, сессия не меняется.

### Окно

- В заголовке дорожки кнопка «A» включает показ линии этой дорожки (одна
  дорожка за раз). Рядом переключатель «Громк.»/«Пан.» — какая линия видна.
- Линия рисуется поверх клипов дорожки; точки — кружки. Пустая линия —
  пунктир на уровне ползунка.
- В строке дорожки с линией: клик — новая точка, перетаскивание точки —
  сдвиг, правый клик по точке — удаление. Клипы этой дорожки в этот момент
  не двигаются.
- Ползунок, которым управляет непустая линия, неактивен.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Пустая автоматизация | звук бит-в-бит как раньше |
| Одна точка громкости 0.5 | вся дорожка ×0.5 |
| Линия громкости 0 → 1 | рампа, в середине ≈ 0.5 |
| Линия панорамы −1 | левый канал = звук, правый — тишина |
| Две точки с одним временем | `InvalidAutomation` |
| Значение NaN, громкость 1.5, панорама −2 | `InvalidAutomation` |
| 1025 точек | `InvalidAutomation { point: 1024 }` |
| JSON без `automation` | пустая автоматизация |
| `move_point` за соседа | время зажимается |

## Критерии приёмки

- [ ] Модель: `value_at`, `validate` для каждого случая.
- [ ] JSON: круговой тест; старый документ; ошибки.
- [ ] Рендер: пустая автоматизация бит-в-бит; одна точка; рампа; панорама.
- [ ] Сторож аллокаций: дорожка с автоматизацией не аллоцирует.
- [ ] Редактор: добавление, замена, сдвиг с зажимом, удаление, отмена,
  ошибки.
- [ ] Goldens не тронуты; gate зелёный.

## Вне области

Автоматизация параметров эффектов, кривые (не линейные), режимы записи
автоматизации (Touch/Latch), mute-автоматизация, живое изменение без
перезапуска.
