# SPEC-049: Типы дорожек и диалог «Новая дорожка»

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Раньше аудио- и MIDI-дорожки ничем не различались. Аудиорегион можно было
перетащить на MIDI-дорожку, а запись попадала на любую выбранную дорожку.
Пункт «Новая дорожка» добавлял только MIDI-дорожку с готовым регионом. В Logic
у каждой дорожки есть тип, а дорожки создаются через диалог с выбором типа и
количества.

## Цель

Ввести у дорожки тип (аудио / программный инструмент), сохранять его в проекте
и соблюдать во всех правках. Добавить диалог создания дорожек в стиле Logic.

## Критерии приёмки

### §1 Типы
`TrackKind::{Audio, Instrument}`. Аудиодорожка принимает только аудиорегионы,
инструментальная — только MIDI-регионы. `add_midi_track` создаёт
инструментальную дорожку.

### §2 Сохранение
Проект пишет `"kind": "instrument"` только для инструментальных дорожек. При
чтении `"audio"` и `"instrument"` разбираются, любое другое значение — ошибка
`Malformed`. Если ключа нет (старые проекты), дорожка с MIDI-регионами
считается инструментальной, иначе — аудио.

### §3 Диалог
«Дорожка → Новые дорожки…», Ctrl+Alt+N, кнопка «＋ Дорожка» на панели и
контекстное меню пустого места открывают модальное окно «Новая дорожка».
В нём: выбор типа (две карточки), количество (от 1 до свободного места до
`MAX_TRACKS`), имя. Enter — создать, Esc — отмена. Все дорожки добавляются
одним шагом отмены, выделяется первая из них. Пустое имя заменяется на
«Аудио» или «Инструмент»; при количестве больше 1 к имени добавляется « N».
Нулевое количество — ошибка, превышение лимита — ошибка без изменений.

### §4 Запрет неверного размещения
Перенос (одиночный и групповой), вставка и дублирование региона на дорожку
другого типа отклоняются с `WrongTrackKind`, проект не меняется. Импорт аудио
на инструментальную дорожку создаёт новую аудиодорожку.

### §5 Запись только на аудиодорожки
Взятая запись ложится только на взведённые аудиодорожки. Если таких нет,
используется выделенная дорожка, но только аудио; иначе создаётся новая
аудиодорожка «Запись». Полоса записи рисуется только для взведённых
аудиодорожек.

### §6 Новый MIDI-регион
Двойной щелчок по пустому месту инструментальной дорожки создаёт пустой
MIDI-регион длиной в такт с привязкой к сетке и открывает пианоролл. На
аудиодорожке `add_midi_region` возвращает `WrongTrackKind`.

### §7 Отображение
Значок в заголовке дорожки и строка «Тип» в инспекторе берутся из типа
дорожки, а не из содержимого.

## Граничные случаи

- Лимит дорожек исчерпан: кнопка «Создать» неактивна, показано предупреждение.
- `add_midi_region` с нулевой длиной — `EmptyClip`, с несуществующей
  дорожкой — `NoClip`.
