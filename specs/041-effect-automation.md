# SPEC-041: Автоматизация параметров эффектов

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

SPEC-023 дал линии громкости и панорамы. Параметры эффектов (SPEC-022)
постоянны: нельзя «открыть» реверб к припеву или поднять верха EQ на
переходе. Нужна общая база автоматизации, в которую линии эффектов
встраиваются так же, как громкость и панорама.

## Поведение

### Параметры эффектов (`audio_core::fx`)

- `EffectParam` — по одному варианту на каждый параметр стоковых эффектов:
  EQ `low_db`, `mid_db`, `mid_hz`, `high_db`; компрессор `threshold_db`,
  `ratio`, `attack_ms`, `release_ms`, `makeup_db`; реверб `room`, `damp`,
  `mix`. Имена уникальны среди всех эффектов.
- `EffectParam::ALL`, `name()` / `from_name(&str)` (имя как в JSON
  эффекта), `range()` — те же диапазоны, что в `EffectKind::is_valid`,
  `of(&EffectKind) -> &[EffectParam]` — параметры типа,
  `get(&EffectKind) -> Option<f32>`, `set(&mut EffectKind, f32) -> bool`
  (`None`/`false`, если параметр не от этого типа).
- `EffectProcessor::update(&EffectKind)` меняет параметры **на месте**: без
  аллокаций, состояние фильтров, огибающая компрессора и буферы реверба
  сохраняются. Тип эффекта сменить нельзя (другой тип — без изменений).
  Обработчик выключенного (bypass) слота не меняется.
- EQ держит все три полосы; полоса с 0 dB пропускается, поэтому плоский EQ
  по-прежнему бит-в-бит, goldens не меняются.

### Модель (`audio_core::session`)

- `Lane::Effect { slot: u8, param: EffectParam }` — линия параметра эффекта
  в слоте `slot` цепочки дорожки. `range()` — диапазон параметра.
  Отображение: `effect <slot> <name>`.
- `Automation::effects: Vec<EffectLane>`,
  `EffectLane { slot, param, points }`. `lane(Lane)` для отсутствующей
  линии эффекта — пустой срез; `lane_mut` создаёт пустую линию.
  `prune()` убирает пустые линии эффектов. `is_empty` учитывает все линии.
- Проверка (`Session::validate`) — `SessionError::InvalidAutomation`:
  прежние правила для каждой линии; кроме того линия эффекта, у которой
  слота нет, тип эффекта в слоте не тот, или пара (слот, параметр)
  повторяется, даёт ошибку с `point = 0`. Не больше
  `MAX_EFFECTS_PER_TRACK × 12` линий эффектов.

### Рендер (`daw_app::nodes::Track`)

- Нет линий эффектов — прежний путь, звук бит-в-бит.
- Иначе квант обрабатывается кусками по `EFFECT_AUTOMATION_STEP = 32`
  сэмпла: в начале куска значение каждой линии
  (`Automation::value_at`) записывается в параметры слота, и обработчик
  слота обновляется `update`, затем цепочка обрабатывает кусок.
- Без аллокаций, блокировок и паник. Экспорт учитывает линии.

### JSON

- В `"automation"` дорожки, если есть непустые линии эффектов:
  `"effects": [{"slot": 0, "param": "mix", "points": [{"time": 0, "value": 0.2}]}]`.
  Пустые линии не пишутся. Ключи `slot`, `param`, `points` обязательны,
  лишние — ошибка, неизвестное имя параметра — ошибка. `version` остаётся 1.

### Редактор (`daw_gui::Editor`)

- `add_point`/`move_point`/`remove_point`/`clear_lane` принимают
  `Lane::Effect`. После удаления точек пустая линия эффекта убирается.
- `remove_effect` удаляет линии этого слота и сдвигает линии следующих
  слотов; `move_effect` переносит линии вместе с эффектом.

### Окно

- Переключатель линии рядом с «A» — выпадающий список: «Громк.», «Пан.» и
  параметры каждого эффекта дорожки («1 Reverb · Mix» и т. п.).
- Пустая линия эффекта — пунктир на уровне текущего значения параметра.

## Критерии приёмки

- [ ] `update` без аллокаций, сохраняет состояние; плоский EQ бит-в-бит.
- [ ] Линия `mix` реверба меняет выход; пустые линии — звук как раньше.
- [ ] Неверный слот/тип/дубликат отвергаются проверкой.
- [ ] JSON туда-обратно сохраняет линии эффектов; старые файлы читаются.
- [ ] Удаление и перенос эффектов переносят линии.
- [ ] Трек с линией эффекта не аллоцирует в `process`.
