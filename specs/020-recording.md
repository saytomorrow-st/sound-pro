# SPEC-020: Запись с микрофона

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

В окне можно только импортировать готовые WAV. Записать голос или гитару с
микрофона нельзя.

## Поведение

### Захват звука (`daw_app::capture`)

- `capture(capacity, sample_rate) -> (CaptureControl, CaptureEngine)`. Всё
  выделяется здесь: SPSC-кольцо `rtrb` на `capacity` отсчётов.
- `CaptureEngine::push(input, channels)` — вызывается из колбэка входа.
  Сводит кадр в моно (среднее по каналам) и кладёт в кольцо. Не аллоцирует,
  не блокирует, не паникует. `channels == 0` — ничего не делает. Если кольцо
  полно, лишние кадры отбрасываются и считаются в `dropped()`.
- `CaptureControl::drain()` — забирает всё из кольца в свой буфер (в потоке
  окна). `frames()` — сколько кадров уже забрано. `finish()` — забирает
  остаток и возвращает `Recording { samples, sample_rate, dropped }`.
- `daw_app::realtime::start_input(preferred_rate, seconds)` (фича
  `realtime`) открывает микрофон по умолчанию, формат f32, на частоте
  `preferred_rate` или ближайшей, что есть у устройства. Кольцо вмещает
  `seconds` секунд. Возвращает `(CaptureControl, RealtimeHandle)`; частоту
  сообщает `CaptureControl::sample_rate()`. Нет устройства →
  `RealtimeError::NoInputDevice`.

### Добавление записи в проект (`Editor::add_recording`)

- `add_recording(samples, rate, start, dir) -> Result<(track, clip)>`:
  - пустая запись → `EditorError::EmptyRecording`, ничего не меняется;
  - звук переводится в частоту проекта (SPEC-019);
  - файл `rec-NNN.wav` (32-бит float, моно, частота проекта) пишется в `dir`;
    `NNN` — первый свободный номер с 001; папка создаётся при надобности;
  - клип начинается в `start` на выбранной дорожке, иначе на новой дорожке
    «Запись»;
  - это один шаг отмены; клип становится выбранным, проект — изменённым.
- Папка записей: `Editor::recordings_dir()` — `<папка проекта>/audio` у
  сохранённого проекта, иначе `<temp>/sound-pro-recordings`.

### Окно

- Кнопка «⏺» на панели транспорта и клавиша R. Во время записи проект
  играет с позиции курсора (если в нём есть звук), курсор идёт вперёд.
- Повторное нажатие «⏺», «⏹» или пробел останавливают запись; запись
  добавляется клипом с той позиции, где начали. Статус: «Записано N.N с».
- Ошибка устройства показывается в строке статуса, проект не меняется.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Стерео-вход | Среднее каналов |
| Кольцо переполнено | Кадры отброшены, `dropped` > 0, без паники |
| Пустая запись | `EmptyRecording`, проект без изменений |
| `rec-001.wav` уже есть | Пишется `rec-002.wav` |
| Частота микрофона ≠ частоте проекта | Перевод частоты при добавлении |
| Лимит клипов на дорожке | `Session(TooManyClips)`, файл не пишется |
