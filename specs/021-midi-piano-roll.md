# SPEC-021: MIDI-дорожки и piano roll

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

В проекте есть только звуковые клипы из WAV. Нарисовать мелодию нотами и
услышать её встроенным синтезатором (SPEC-009) нельзя.

## Поведение

### Модель (`audio_core::session`)

- `Note { pitch: u8, start: u64, length: u64, velocity: u8 }`. `start` —
  отсчёт от начала содержимого клипа (как `offset_samples`), `length` —
  длительность в отсчётах.
- `Clip.notes: Option<Vec<Note>>`. `Some` — MIDI-клип, `None` — звуковой.
  `Clip::midi(start, length)` — пустой MIDI-клип, `source_length == length`.
- `Clip::is_midi()`.
- `Session::validate` дополнительно проверяет MIDI-клипы и возвращает
  `SessionError::InvalidNote { track, clip, note }`, если:
  - у клипа одновременно есть `source` и `notes`;
  - `pitch > 127`, `velocity` не в `1..=127`, `length == 0`;
  - нота кончается позже `source_length` (переполнение — тоже ошибка);
  - нот больше `MAX_NOTES_PER_CLIP` (4096; `note` = 4096).
- Пустой список нот допустим: клип звучит тишиной.

### Звук нот (`audio_core::synth::render_notes`)

- `render_notes(notes, sample_rate, frames) -> Result<Vec<f32>, SynthError>`
  — моно-звук нот через `Synth` с конвертом по умолчанию, ровно `frames`
  отсчётов. Вызывается при загрузке сессии, не в аудиопотоке: функция
  аллоцирует. Звучащий «хвост» отпускания после `frames` обрезается.
- Детерминирован: два вызова дают одинаковые отсчёты. Нота на `start = k`
  молчит до `k`. Пустой список — тишина. Ноль частоты —
  `SynthError::InvalidSampleRate`.

### Проект (`project.rs`)

- В клипе необязательное поле `"notes": [{"pitch", "start", "length",
  "velocity"}]`. Пишется только у MIDI-клипов (включая пустой список), так
  что старые проекты не меняются. Неизвестный ключ внутри ноты, нехватка
  поля или неверный тип — ошибка разбора, как у остальных полей.

### Загрузка (`daw_app::load_session`)

- Для MIDI-клипа источник — `render_notes(notes, rate, source_length)`;
  файл не нужен. Ошибка синтезатора — `LoadError::Synth`.

### Редактор (`Editor`)

- `add_midi_track(start, length) -> (track, clip)` — новая дорожка «MIDI»
  с пустым MIDI-клипом; `length == 0` → `EditorError::EmptyClip`.
- `add_note(track, clip, note) -> Result<usize>` — индекс новой ноты;
  ноты в клипе отсортированы по `(start, pitch)`.
- `delete_note(track, clip, index)`, `move_note(track, clip, index, start,
  pitch) -> Result<usize>` — новый индекс.
- Не MIDI-клип, неверный индекс или нота, нарушающая проверки модели, →
  `EditorError::InvalidNote`, проект не меняется.
- Каждая правка — один шаг отмены, проект становится изменённым.

### Окно

- Меню «Дорожка → Новая MIDI-дорожка»: MIDI-клип на 4 такта с позиции
  курсора, он же выбирается и открывается в piano roll.
- На таймлайне MIDI-клип рисуется своим цветом с нотами-чёрточками.
- Двойной клик по MIDI-клипу открывает piano roll внизу окна; «✕»
  закрывает.
- Piano roll: клавиши слева, сетка по 1/16 такта. Клик по пустому месту
  добавляет ноту длиной 1/16 (силой 100), правый клик по ноте удаляет,
  перетаскивание сдвигает ноту по времени и высоте с привязкой к 1/16.
  Ноты звучат при воспроизведении проекта.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Нота за концом клипа | `InvalidNote`, проект без изменений |
| `velocity == 0` | `InvalidNote` |
| `source` и `notes` в одном клипе | `InvalidNote` при проверке/разборе |
| Пустой MIDI-клип | Тишина, проект сохраняется и открывается |
| Старый проект без `notes` | Читается как раньше |
| Больше 16 одновременных нот | Синтезатор крадёт голоса (SPEC-009) |

## Чего не делаем

Импорт `.mid` в клип, выбор инструмента, изменение длины и силы ноты мышью,
квантизация, аудиопоток не меняется (ноты рендерятся при загрузке).
