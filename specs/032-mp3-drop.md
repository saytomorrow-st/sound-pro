# SPEC-032: MP3 и перетаскивание файлов на таймлайн

## Цель

Для тестов нужно быстро класть готовую музыку под дорожки. Окно принимает
WAV и MP3: через «Импорт» и перетаскиванием из файлового менеджера.

## Поведение

1. `daw_app::audio_file` читает WAV (как раньше) и MP3 (symphonia, только
   декодер MP3). Тип определяется по расширению без учёта регистра.
   Многоканальный файл сводится в моно, частота приводится к частоте проекта.
2. Клип проекта с `source` на MP3 играет и экспортируется так же, как WAV.
3. Диалог «Импорт» показывает WAV и MP3.
4. Перетаскивание на таймлайн:
   - на строку дорожки — клип ложится на эту дорожку, начало под курсором мыши;
   - ниже последней дорожки (или в пустой проект) — новая дорожка с именем файла;
   - несколько файлов идут друг за другом на одной дорожке;
   - файлы не WAV/MP3 пропускаются; если ничего не подошло — сообщение;
   - пока файл тянут над окном, целевая строка подсвечивается.
5. Каждый добавленный файл — один шаг отмены; выделяется новый клип.

## Ошибки

- Битый MP3 → `EditorError::Decode` (или `EmptyFile`, если звука нет),
  проект не меняется, отмена не записывается. Паники нет.
- При загрузке проекта битый MP3 → `LoadError::Decode`.

## Вне рамок

FLAC/OGG/AAC, потоковое чтение длинных файлов, точная компенсация задержки
кодера MP3.

## Приёмка

- `crates/daw-app/tests/audio_file.rs`, `crates/daw-gui/tests/drop.rs`.
- Фикстура `crates/daw-app/tests/data/sine.mp3` (0,5 с, 440 Гц, 48 кГц, моно),
  сделана `ffmpeg -f lavfi -i sine=frequency=440:duration=0.5 -ac 1 -ar 48000 -b:a 64k`.
