# SPEC-048: Инспектор в духе Logic Pro

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

Инспектор был «кашей»: разнородные подписи, длинные списки серых
неработающих параметров вперемешку с рабочими, нельзя переименовать регион,
нет цвета и типа дорожки, нельзя изменить громкость сразу у нескольких
выделенных регионов.

## Цель

Компактный инспектор: секции «Регион» и «Дорожка» с заголовком-именем,
ровная сетка «подпись — значение», заглушки убраны в свёрнутый блок «Ещё».

## Критерии приёмки

### §1 Заголовки
Секции называются «Регион: <имя>» («Регион: выбрано N» при нескольких)
и «Дорожка: <имя>», по умолчанию раскрыты.

### §2 Сетка
Две колонки: серые подписи выровнены вправо по фиксированной ширине, значения
слева. Регион: Имя, Тип, Позиция, Длина, затем Gain/Fade/Кроссфейд для аудио
или Quantize/Transpose/Velocity/Gate Time для MIDI.

### §3 Заглушки
Нереализованные параметры показаны только в свёрнутом блоке «Ещё».

### §4 Групповой Gain
Если выделено несколько регионов и среди них текущий, Gain меняется у всех
сразу; одно изменение — один шаг отмены; выделение сохраняется. Неверные
индексы пропускаются; если верных нет — ошибка `NoClip`.

### §5 Имя региона
Поле «Имя» переименовывает регион при потере фокуса. Пробелы по краям
обрезаются, пустое имя — ошибка `EmptyName`, слишком длинное — ошибка сессии.
Одно переименование — один шаг отмены.

### §6 Дорожка
Строки Имя, Тип (Аудио / Инструмент (MIDI)), Канал, Цвет (палитра; повторный
клик снимает цвет), остальное в «Ещё».

## Граничные случаи

- Gain вне 0..1 обрезается, NaN считается 0.
- Gain, не меняющий значения, не создаёт шаг отмены.
