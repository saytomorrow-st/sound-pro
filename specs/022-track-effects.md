# SPEC-022: Эффекты на дорожках — EQ, компрессор, реверб

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

У дорожки есть только громкость, панорама, mute и solo. Нельзя подрезать
низ или верх, выровнять громкость компрессором или добавить пространство.
В любой DAW это делается цепочкой эффектов в слотах микшера.

## Поведение

### Модель (`audio_core::session`)

- `Track::effects: Vec<Effect>` — цепочка эффектов, по умолчанию пустая.
  Обрабатывается по порядку списка.
- `Effect { bypass: bool, kind: EffectKind }`. С `bypass = true` эффект
  пропускает звук без изменений.
- `EffectKind`:
  - `Eq { low_db, mid_db, mid_hz, high_db }` — три полосы: полка низа на
    200 Гц, колокол (Q = 1) на `mid_hz`, полка верха на 5000 Гц.
  - `Compressor { threshold_db, ratio, attack_ms, release_ms, makeup_db }`.
  - `Reverb { room, damp, mix }`.
- `EffectKind::eq()`, `compressor()`, `reverb()` — нейтральные умолчания:
  EQ 0/0/1000/0; компрессор −18 дБ, 4:1, 10 мс, 100 мс, 0 дБ;
  реверб 0.5/0.5/0.25.
- Диапазоны (все значения конечны):

| Поле | Диапазон |
|---|---|
| `low_db`, `mid_db`, `high_db` | −24 … 24 |
| `mid_hz` | 100 … 10000 |
| `threshold_db` | −60 … 0 |
| `ratio` | 1 … 20 |
| `attack_ms` | 0.1 … 100 |
| `release_ms` | 10 … 1000 |
| `makeup_db` | 0 … 24 |
| `room`, `damp`, `mix` | 0 … 1 |

- Не больше `MAX_EFFECTS_PER_TRACK = 8` эффектов на дорожку.
- `Session::validate` после клипов дорожки проверяет эффекты:
  вне диапазона, NaN или слишком длинная цепочка —
  `SessionError::InvalidEffect { track, effect }` (для длинной цепочки
  `effect = MAX_EFFECTS_PER_TRACK`).

### DSP (`audio_core::fx`)

- `EffectProcessor::new(&Effect, sample_rate)` выделяет всю память;
  `process(&mut self, samples: &mut [f32])` обрабатывает моно-блок на месте,
  без аллокаций, блокировок и паник.
- EQ — биквады по формулам Audio EQ Cookbook (R. Bristow-Johnson): low shelf
  и high shelf с наклоном S = 1, peaking с Q = 1. Полоса с усилением ровно
  0 дБ пропускается, поэтому EQ «0/0/0» не меняет звук **бит-в-бит**.
- Компрессор — прямой, пиковый детектор с одним полюсом:
  `coef = exp(-1 / (t · rate))`, атака при росте огибающей, отпускание при
  спаде. Выше порога уменьшение `(L − T)·(1 − 1/ratio)` дБ, затем makeup.
  Ниже порога и с makeup 0 множитель ровно `1.0` — звук не меняется.
- Реверб — моно-схема Шрёдера–Мурера в виде Freeverb (общедоступный
  алгоритм Jezar, 2000): 8 параллельных гребенчатых фильтров с затуханием в
  обратной связи и 4 последовательных всепропускающих; длины задержек
  масштабируются от 44,1 кГц к частоте сессии. `room` — обратная связь
  `0.7 + 0.28·room`, `damp` — затухание `0.4·damp`, `mix` — доля мокрого
  сигнала (`dry = 1 − mix`).
- Тишина на входе любого эффекта даёт тишину (точные нули) на выходе, пока
  в нём нет хвоста.

### Рендер

- `nodes::Track` после моно-суммы клипов и до громкости и панорамы
  пропускает блок через эффекты дорожки (те, что без `bypass`).
- Эффекты работают и там, где клипов нет, чтобы хвост реверба звучал после
  клипа. После конца сессии хвост обрезается (как и раньше заканчивается
  рендер).
- Пустая цепочка — звук **бит-в-бит** как до SPEC-022, goldens не меняются.
- Правки эффектов во время игры слышны после следующего Play (как в
  SPEC-016).

### JSON

- У дорожки после `clips` пишется `"effects": [...]`, **только если список
  не пуст**. Эффект — объект с ключами `type` (`"eq"`, `"compressor"`,
  `"reverb"`), `bypass` и полями своего типа.
- При чтении `effects` и `bypass` необязательны (умолчания: пусто и
  `false`). Старые файлы открываются как есть, `version` остаётся `1`.
- Неизвестный `type`, неизвестный ключ, нехватка поля типа — ошибки, как для
  клипов (`UnknownField`, `MissingField`, `Malformed`). Слишком длинный
  список отвергается до разбора элементов.

### Редактор (`daw_gui::Editor`)

- `add_effect(track, kind) -> Result<usize, EditorError>` — добавляет в
  конец, возвращает индекс.
- `remove_effect(track, index)`, `set_effect(track, index, Effect)`,
  `move_effect(track, from, to)`.
- Всё через проверку сессии и с отменой. Нет дорожки или эффекта —
  `EditorError::NoEffect`; девятый эффект или значение вне диапазона —
  `EditorError::Session(InvalidEffect)`, сессия не меняется.

### Окно

- В заголовке дорожки кнопка «FX» (с числом эффектов, если они есть).
- Она открывает окно «Эффекты — <дорожка>»: кнопки «+ EQ», «+ Компрессор»,
  «+ Реверб»; для каждого эффекта — название, «Обход», «▲»/«▼», «✕» и
  слайдеры параметров. Одно движение слайдера — один шаг отмены.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Пустая цепочка | звук бит-в-бит как раньше |
| EQ 0/0/0 дБ | звук бит-в-бит |
| Все эффекты в обходе | звук бит-в-бит |
| Компрессор, сигнал ниже порога, makeup 0 | звук бит-в-бит |
| Компрессор 0 дБ полный синус, порог −20, ratio 20 | пик выхода ≤ −17 дБ после атаки |
| Реверб, импульс | после импульса ненулевой хвост ещё > 0,5 с |
| Реверб `mix = 0` | звук бит-в-бит |
| Тишина на любой эффект | точные нули |
| 9 эффектов | `InvalidEffect { effect: 8 }` |
| `ratio = 0.5`, `mid_hz = NaN` | `InvalidEffect` |
| JSON без `effects` | пустая цепочка |
| `"type": "flanger"` | ошибка разбора |

## Критерии приёмки

- [ ] Юнит-тесты `fx`: каждая строка таблицы про DSP; EQ +12 дБ на низах
  усиливает 50 Гц и почти не трогает 10 кГц; частотная проверка peak.
- [ ] Модель: умолчания, `validate` для каждого поля и длины цепочки.
- [ ] JSON: круговой тест со всеми тремя типами; старый документ; ошибки.
- [ ] Рендер (`crates/daw-app/tests`): пустая цепочка не меняет рендер;
  компрессор снижает уровень; реверб даёт хвост после клипа.
- [ ] Сторож аллокаций: дорожка с тремя эффектами не аллоцирует.
- [ ] Редактор: добавление, правка, перестановка, удаление, отмена,
  ошибки.
- [ ] Goldens не тронуты; gate зелёный.

## Вне области

Стерео-эффекты, посылы и шины, сайдчейн, плагины VST/CLAP, автоматизация
параметров, метры, живое изменение без перезапуска, хвост после конца
сессии.
