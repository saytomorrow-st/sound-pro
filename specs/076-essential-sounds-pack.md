# SPEC-076: мета-пакет «Основной набор» (Essential Sounds Pack)

Статус: implemented
Владелец: saytomorrow-st

> Реализовано. «Основной набор» — захардкоженный список из 8 id каталога в
> `crates/daw-app/src/essential_sounds.rs` (`ESSENTIAL_BANK_IDS`), а не
> отдельный манифест (см. «Реализация» ниже).

## Проблема

Пользователь после установки получает одно пианино; Apple Logic Pro даёт
«Essential Sounds» — набор инструментов по категориям. Решение владельца
(вариант D): SFZ-паки по категориям через существующие каталог
(`bank_library.rs`) и загрузчик (`bank_download.rs`). Размер не критичен,
ориентир ~3–4 ГБ; VSCO-2-CE (CC0, ~2,3 ГБ) — оркестр основного набора.
Лицензии проверены в `catalog/audit/essential-sounds-licenses.md`.

## Лицензионная политика

Банки не хостятся в проекте — они скачиваются с сайта автора после проверки
лицензии. В каталоге каждый банк получает одну из трёх меток лицензии
(`bank_library::LicenseClass`):

- **«Свободно»** — CC0 / Public Domain: использовать и монетизировать без ограничений.
- **«Нужно указать автора»** — CC-BY / MIT и т. п.: использовать можно, но автора
  нужно указать (текст описания релиза генерируется автоматически).
- **«Только некоммерческое»** — NC (CC-BY-NC и т. п.): использовать можно, но
  монетизировать нельзя. Перед установкой показывается предупреждение.

Запрещены только GPL и share-alike (CC-BY-SA и т. п.). Некоммерческие (NC)
лицензии разрешены с меткой и предупреждением.

## Поведение

1. **Мета-пакет** — файл `catalog/packs/essential-sounds.json` (отдельный от
   `catalog/banks/*.json`): `schema`, `id`, `name`, `version`, список
   `categories[]`, в каждой — `parts[]` со ссылкой на `bank_id` существующей
   записи каталога и флагом `required: true|false`. Пакет **не содержит**
   сэмплов, SHA-256 или URL: всё это берётся из записей банков.
2. **Схема каталога 1 не меняется.** `CATALOG_SCHEMA`, `CatalogEntry` и
   `validate_catalog_entry` не трогаются; пакет живёт в своём файле со своей
   версией схемы. Банк в пакете проходит ту же валидацию, что и вне его
   (запрещены только GPL и share-alike; CC-BY требует атрибуции,
   некоммерческие (NC) разрешены с меткой «Только некоммерческое»).
3. **Категории и заготовка** (размеры из `sfzinstruments.github.io`
   `data/sfz/instruments.yml`; всё, что не подтверждено, помечено):

   в пределах ориентира 3–4 ГБ.
4. **Общий размер** показывается в UI до начала загрузки: сумма
   `download.size_bytes` выбранных частей, а не оценка.
5. **Выбор категорий.** По умолчанию отмечены обязательные части всех
   категорий; пользователь снимает/добавляет категории и необязательные части.
   Пакет без части, отмеченной `required`, считается «неполным», но
   работоспособным: недостающая часть остаётся доступной для докачки.
6. **Порядок загрузки**: по возрастанию размера внутри приоритета —
   сначала пианино и эл. пианино, затем остальные категории, VSCO-2-CE
   последним. Загрузка последовательная (по одному банку), каждая часть
   проходит существующие проверки (`bank_download`: SHA-256, лимиты,
   redirect_hosts, `license_check`).
7. **Докачка**: состояние пакета = множество установленных `bank_id` в
   реестре банков. Повторный запуск пропускает установленные части и
   продолжает с первой неустановленной; прерванная часть докачивается
   средствами `bank_download` (SHA-256 всей части проверяется по завершении).
   Отдельных «файлов состояния пакета» нет.
8. **Realtime-контракт.** Скачивание, распаковка, проверка хэшей и лицензий,
   сборка кэша — только в фоновых потоках; `Graph::process`/`Renderer::render`
   не меняются и не блокируются, прогресс — через атомарные счётчики
   (образец `bank_download::Progress`, SPEC-067; `CacheBuildProgress`,
   SPEC-075). Ни одна часть пакета не загружается в аудиопотоке.
9. **Credits.** Экран/файл Credits формируется из записей каталога: для каждой
   установленной части — имя, автор, SPDX, `attribution`, `source_url`.
   Для CC-BY-3.0/4.0 (Greg Sullivan, Ixox Flute, Muldjord Kit) атрибуция
   обязательна и не скрывается; для CC0 и PD — показывается по доброй воле.
   Credits содержит ссылку на `catalog/audit/*.md`.

## Реализация (как сделано, вместо манифеста)

Выбран простой вариант: «Основной набор» — **захардкоженный список id** в
`crates/daw-app/src/essential_sounds.rs`, а не файл `catalog/packs/*.json`
(варианты из «Поведения» выше остаются справочными). Причины: пакет мал,
версионируется вместе с бинарём, и не требует новой схемы каталога.

- `ESSENTIAL_BANK_IDS` — 8 банков CC0/CC-BY (базовый набор из брифа):
  Salamander Grand, Virtuosity Drums, Shinyguitar, Meatbass, Bigcat Cello,
  Bear Sax, String Cyborgs, Merry Orks. Банк, которого нет в каталоге,
  непроверенный или без известного размера, пропускается (не валит пакет).
- `essential_banks()` / `essential_banks_missing()` / `essential_installed()` /
  `essential_download_bytes()` — резолв и состояние установки из реестра
  банков на диске (единый статус «Не установлено / Загрузка / Установлено /
  Не завершено» читается из реального состояния диска, не из флага).
- **Очередь** `crates/daw-app/src/download_queue.rs` (`DownloadQueue`): батч
  банков в фоновом потоке, общий прогресс в байтах и по банкам, скорость и
  ETA (форматирование с десятичной запятой, «Xм Yс»), пауза/продолжение,
  отмена. Каждый банк качается через `bank_download::download_bank_into`.
  Прогресс отдаётся снимком `QueueSnapshot` (мьютекс) — GUI читает его каждый
  кадр, вся I/O остаётся в воркере (realtime-контракт соблюдён).
- **Загрузчик** `bank_download.rs`: докачка частично скачанного через
  HTTP Range, повторная проверка SHA-256 после загрузки, распаковка,
  атомарная установка (временный каталог → `rename`), повтор при сетевой
  ошибке с ограничением.
- **Шаг первого запуска** (`welcome`): при «Полный режим» стартует
  `start_essential_queue`; прогресс-бар/байты читаются из `QueueSnapshot`;
  кнопки «Пауза»/«Продолжить», «Отмена», «Загрузить», «Загрузить позже»;
  по чистом завершении — авто-переход к «Доступно больше звуков».
- **Меню «Библиотека звуков»** (`macos_menu.rs`): «Загрузить основные звуки»
  неактивно, когда essential установлены; «Загрузить все доступные звуки» —
  все непроверенные банки; «Переустановить библиотеку звуков» — перекачка
  essential с проверкой SHA; «Переместить библиотеку звуков…» — заглушка.
- **Менеджер**: «Установить» ставит выбранные банки через очередь (общий
  прогресс, пауза/отмена внутри окна); строки «Установлено / Не установлено»
  и реальные размеры «N ГБ загрузка / требуется M ГБ».

## Поддержка архивов

`bank_download.rs::unpack_archive` распаковывает:

- `zip` (crate `zip`), `tar.gz` (crate `flate2`), `tar.bz2` (`bzip2`),
  `tar.xz` (`xz2`, feature `static` — связывает liblzma, C), `7z`
  (`sevenz-rust`, чистый Rust). Формат из записи каталога берётся из
  `format`/расширения URL; неизвестный формат отклоняется явным
  «формат не поддерживается».
- Все пути внутри архива валидируются (`validate_entry_name` + `safe_join`)
  против обхода каталога и коллизий регистра; симлинки/hardlink отклоняются.
- `7z` не различает симлинки от обычных файлов (хранятся как обычные файлы) —
  задокументировано в коде.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| `bank_id` из пакета отсутствует в каталоге | часть пропускается, пакет «неполный», ошибка в логе |
| Часть не прошла `license_check`/SHA-256 | часть не ставится, остальные продолжаются |
| Нет места на диске | загрузка останавливается до начала части; уже установленное остаётся |
| Пользователь отменил | установленные части остаются, остальные докачиваются позже |
| Банк входит в две категории (VSCO-2-CE) | скачивается один раз |
| Пакет ссылается на банк с запрещённой лицензией | пакет отвергается целиком при загрузке манифеста |

## Критерии приёмки

- [ ] Манифест пакета парсится и валидируется; запись с запрещённой лицензией отвергается.
- [ ] Существующие тесты каталога (схема 1) проходят без изменений.
- [ ] Докачка: повторный запуск не качает установленные части (тест на реестре).
- [ ] Credits содержит атрибуцию для всех установленных CC-BY частей.
- [ ] `Graph::process`/`Renderer::render` не затронуты; нет блокировок на горячем пути.
- [ ] Для каждой части существует `catalog/audit/<bank_id>.md` с реальным SHA-256.

## Вне области

- Реализация кода пакета и записей каталога для новых банков (отдельные SPEC).
- Закрытие дыр, помеченных «не подтверждено».
- Хостинг сэмплов: мы по-прежнему ничего не хостим.
