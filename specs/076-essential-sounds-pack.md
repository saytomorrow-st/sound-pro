# SPEC-076: мета-пакет «Основной набор» (Essential Sounds Pack)

Статус: draft
Владелец: saytomorrow-st
Для агента: запрещено реализовывать (сначала закрыть дыры и аудит, см. ниже)

## Проблема

Пользователь после установки получает одно пианино; Apple Logic Pro даёт
«Essential Sounds» — набор инструментов по категориям. Решение владельца
(вариант D): SFZ-паки по категориям через существующие каталог
(`bank_library.rs`) и загрузчик (`bank_download.rs`). Размер не критичен,
ориентир ~3–4 ГБ; VSCO-2-CE (CC0, ~2,3 ГБ) — оркестр основного набора.
Лицензии проверены в `catalog/audit/essential-sounds-licenses.md`.

## Поведение

1. **Мета-пакет** — файл `catalog/packs/essential-sounds.json` (отдельный от
   `catalog/banks/*.json`): `schema`, `id`, `name`, `version`, список
   `categories[]`, в каждой — `parts[]` со ссылкой на `bank_id` существующей
   записи каталога и флагом `required: true|false`. Пакет **не содержит**
   сэмплов, SHA-256 или URL: всё это берётся из записей банков.
2. **Схема каталога 1 не меняется.** `CATALOG_SCHEMA`, `CatalogEntry` и
   `validate_catalog_entry` не трогаются; пакет живёт в своём файле со своей
   версией схемы. Банк в пакете проходит ту же валидацию, что и вне его
   (запрещены NC/ND/share-alike/GPL; CC-BY требует атрибуции).
3. **Категории и заготовка** (размеры из `sfzinstruments.github.io`
   `data/sfz/instruments.yml`; всё, что не подтверждено, помечено):

   в пределах ориентира 3–4 ГБ.
4. **Общий размер** показывается в UI до начала загрузки: сумма
   `download.size_bytes` выбранных частей, а не оценка.
5. **Выбор категорий.** По умолчанию отмечены обязательные части всех
   категорий; пользователь снимает/добавляет категории и необязательные части.
   Пакет без части, отмеченной `required`, считается «неполным», но
   работоспособным: недостающая часть остаётся доступной для докачки.
6. **Порядок загрузки**: по возрастанию размера внутри приоритета —
   сначала пианино и эл. пианино, затем остальные категории, VSCO-2-CE
   последним. Загрузка последовательная (по одному банку), каждая часть
   проходит существующие проверки (`bank_download`: SHA-256, лимиты,
   redirect_hosts, `license_check`).
7. **Докачка**: состояние пакета = множество установленных `bank_id` в
   реестре банков. Повторный запуск пропускает установленные части и
   продолжает с первой неустановленной; прерванная часть докачивается
   средствами `bank_download` (SHA-256 всей части проверяется по завершении).
   Отдельных «файлов состояния пакета» нет.
8. **Realtime-контракт.** Скачивание, распаковка, проверка хэшей и лицензий,
   сборка кэша — только в фоновых потоках; `Graph::process`/`Renderer::render`
   не меняются и не блокируются, прогресс — через атомарные счётчики
   (образец `bank_download::Progress`, SPEC-067; `CacheBuildProgress`,
   SPEC-075). Ни одна часть пакета не загружается в аудиопотоке.
9. **Credits.** Экран/файл Credits формируется из записей каталога: для каждой
   установленной части — имя, автор, SPDX, `attribution`, `source_url`.
   Для CC-BY-3.0/4.0 (Greg Sullivan, Ixox Flute, Muldjord Kit) атрибуция
   обязательна и не скрывается; для CC0 и PD — показывается по доброй воле.
   Credits содержит ссылку на `catalog/audit/*.md`.

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| `bank_id` из пакета отсутствует в каталоге | часть пропускается, пакет «неполный», ошибка в логе |
| Часть не прошла `license_check`/SHA-256 | часть не ставится, остальные продолжаются |
| Нет места на диске | загрузка останавливается до начала части; уже установленное остаётся |
| Пользователь отменил | установленные части остаются, остальные докачиваются позже |
| Банк входит в две категории (VSCO-2-CE) | скачивается один раз |
| Пакет ссылается на банк с запрещённой лицензией | пакет отвергается целиком при загрузке манифеста |

## Критерии приёмки

- [ ] Манифест пакета парсится и валидируется; запись с запрещённой лицензией отвергается.
- [ ] Существующие тесты каталога (схема 1) проходят без изменений.
- [ ] Докачка: повторный запуск не качает установленные части (тест на реестре).
- [ ] Credits содержит атрибуцию для всех установленных CC-BY частей.
- [ ] `Graph::process`/`Renderer::render` не затронуты; нет блокировок на горячем пути.
- [ ] Для каждой части существует `catalog/audit/<bank_id>.md` с реальным SHA-256.
