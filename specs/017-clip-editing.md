# SPEC-017: редактирование клипов мышью

Статус: implemented
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

В окне (SPEC-015/016) клипы можно только импортировать и удалить. Их нельзя
сдвинуть по времени, перенести на другую дорожку или обрезать, а сетки
тактов для точного выравнивания нет.

## Поведение

### Модель (`daw_gui::Editor`, без окна, покрыто тестами)

Все правки атомарны: при ошибке проект не меняется. Удачная правка ставит
флаг «изменён». Неверные индексы — `EditorError::NoClip`.

- `move_clip(track, clip, start, to_track)` ставит клип на позицию `start`
  дорожки `to_track`. На той же дорожке индекс клипа не меняется; на другой
  клип уходит в конец её списка. Возвращает новый `(track, clip)`, он же
  становится выбранным. Полная дорожка — `Session(TooManyClips)`; конец за
  пределами `u64` — `Session(TimelineOverflow)`. Перекрытие клипов
  разрешено (они суммируются).
- `trim_start(track, clip, start)` двигает левый край, правый край стоит на
  месте: меняются `start_samples`, `offset_samples`, `length_samples`.
  Край не уходит левее начала содержимого (`offset ≥ 0`) и ближе одного
  сэмпла к правому краю.
- `trim_end(track, clip, end)` двигает правый край: длина от 1 до
  `source_length − offset`. Левый край и смещение не меняются.
- Значения за пределами обрезки не ошибка, а упор в границу.

### Сетка

- `snap_to_beat(samples, rate, tempo)` — ближайшая доля (4/4) к позиции;
  половина доли округляется вверх. Неверный темп — темп по умолчанию.

### Окно

- Перетаскивание клипа двигает его по времени и между дорожками.
- Перетаскивание за край (6 px у границы, курсор «↔») — обрезка.
- По умолчанию края и начало привязываются к сетке долей; с зажатым `Shift`
  — без привязки. Переключатель «Сетка» в панели транспорта.
- Начало перетаскивания выбирает клип; `Delete` удаляет выбранный (как в
  SPEC-015).
- Правка во время игры слышна после следующего «Играть» (SPEC-016).

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Сдвиг на позицию 0 | клип в начале дорожки |
| Перенос на полную дорожку | `TooManyClips`, проект не изменён |
| Перенос на несуществующую дорожку | `NoClip`, проект не изменён |
| `trim_start` левее начала содержимого | край упирается в `offset = 0` |
| `trim_start` правее правого края | длина 1 |
| `trim_end` дальше конца содержимого | длина `source_length − offset` |
| `trim_end` левее левого края | длина 1 |
| Позиция ровно посередине доли | округление к следующей доле |
