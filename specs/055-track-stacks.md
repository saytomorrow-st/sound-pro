# SPEC-055: Папки дорожек (Track Stacks)

Статус: ready
Владелец: saytomorrow
Для агента: разрешено реализовывать

## Проблема

В проекте с десятками дорожек нет способа сгруппировать их организационно.
Дорожки хранятся плоским списком, и единственный способ навести порядок —
перемещать и переименовывать их по одной. В Logic Pro эту задачу решают
«Track Stacks» (папки дорожек): несколько дорожек объединяются под одной
строкой-заголовком, которую можно свернуть, чтобы не тратить место, и
перемещать/удалять целиком.

Нужна организационная сущность «папка дорожек», которая **не** меняет
маршрутизацию, громкость или любой другой звук. Папка — только структура и
визуальное сворачивание.

## Цель

Ввести папку дорожек в модель проекта и в заголовки дорожек, с созданием из
выделенных дорожек, переименованием, цветом, перемещением, удалением,
сворачиванием/разворачиванием и полным Undo/Redo, не затронув аудио-путь.

## Поведение

### §1 Модель (`audio_core::session`)

- Новая сущность `TrackFolder { name: String, color: Option<u8>, collapsed: bool }`.
  Папка — организационная сущность: у неё нет ни gain, ни pan, ни mute/solo,
  ни эффектов, ни посылов, ни регионов.
- `Session` получает поле `folders: Vec<TrackFolder>` (по умолчанию пусто) и
  поле `folder_children: Vec<Vec<usize>>` (параллельный список: для папки
  `i` — упорядоченный список индексов дочерних дорожек). Индексы адресуют
  `Session::tracks`; один трек может входить не более чем в одну папку.
- Инварианты (проверяются `Session::validate`):
  - `folders.len() == folder_children.len()`;
  - имя папки не длиннее `MAX_NAME_BYTES`;
  - `color` < `TRACK_COLORS` (`SessionError::InvalidColor { track }`, где
    `track` — индекс папки);
  - каждый дочерний индекс < `tracks.len()` и не повторяется ни внутри
    одной папки, ни между папками (`SessionError::FolderChild { folder }`).
- Папки **не влияют** на `length_samples`, `is_audible`, `validate` дорожек,
  маршрутизацию и любой код аудио-пути. Рендер не знает о папках.
- Вложенность запрещена: папка может содержать только дорожки, но не другие
  папки. Обоснование: одноуровневая модель покрывает реальные сценарии
  (группировка партий/слоёв), сохраняет плоский `tracks` (индекс дорожки
  == строка таймлайна, что критично для всей существующей геометрии клипов и
  drag-and-drop) и не требует рекурсивного обхода в аудио-пути. Многоуровневые
  папки вынесены в отдельную спеку, если понадобятся.

### §2 Сериализация (`audio_core::project`)

- В `"session"` добавляется необязательный ключ `"folders"`: массив объектов
  `{ "name": …, "children": [индексы…], "collapsed": bool?, "color": int? }`.
  Ключ пишется **только** когда `folders` не пуст.
- `"collapsed"` пишется только когда `true`; `"color"` — только когда задан.
- Старые проекты без `"folders"` читаются как раньше (пустой список) и
  записываются бит-в-бит как раньше. Round-trip: проект с папками →
  `to_json` → `from_json` → `to_json` даёт тот же текст.
- Неверные значения (неверный тип, индекс ребёнка вне диапазона, повтор
  индекса, имя длиннее лимита) — `ProjectError::Session(...)`.

### §3 Операции редактора (`daw_gui::Editor`)

Каждое действие — один шаг отмены; при ошибке состояние не меняется.

- `create_folder(tracks: &[usize]) -> Result<usize, EditorError>`: создаёт
  папку «Папка N» (N — минимальный незанятый номер), дети — переданные
  дорожки в порядке их следования в сессии. Возвращает индекс папки.
  Ошибка, если любая дорожка уже в папке, индекс вне диапазона, или список
  пуст (`EditorError::Folder...`).
- `create_empty_folder() -> Result<usize, EditorError>`: пустая папка
  вставляется на верхний уровень.
- `delete_folder(folder, mode) -> Result<(), EditorError>`: `mode` —
  `KeepChildren` (дети остаются, папка удаляется) или `DeleteChildren`
  (удаляются и папка, и её дети). `KeepChildren` — безопасный вариант по
  умолчанию.
- `rename_folder(folder, name)`: обрезает пробелы; пустое — `EmptyName`,
  то же имя — без шага отмены.
- `set_folder_color(folder, Option<u8>)`.
- `toggle_folder(folder)`: сворачивает/разворачивает. Только визуальное
  состояние; не трогает данные и звук.
- `move_folder(from, to)`: перемещает папку **вместе со всеми детьми** одной
  командой отмены. Дети в списке дорожек физически переезжают вслед за
  папкой; индексы в `folder_children` пересчитываются.
- `add_tracks_to_folder(folder, tracks)` и `remove_tracks_from_folder(tracks)`.
- `move_track` и `delete_track` учитывают папки: при перемещении дорожки
  индексы детей обновляются; при удалении дорожки, состоящей в папке, она
  удаляется и из списка детей.

Все операции проходят через существующий механизм `record()`/`commit_*`
(полный снимок `Session`), поэтому Undo/Redo покрывает их без нового кода.

### §4 UI (`daw_gui`)

- В панели заголовков дорожек у строки-папки стрелка сворачивания (▸/▾).
  Развёрнутая папка показывает детей с отступом; свёрнутая — только одну
  строку папки, дети скрыты.
- Свёрнутая папка **не** останавливает звук детей и не меняет их состояние —
  только визуально прячет строки.
- Контекстное меню на выделенных дорожках — «Собрать в папку»; на пустом
  месте панели — «Новая папка» (переиспользует существующий пункт меню
  заголовков, не создавая дублирующий механизм создания дорожек).
- Меню папки: «Переименовать», цвет, «Свернуть/Развернуть», «Выше», «Ниже»,
  «Разобрать папку» (дети на верхний уровень), «Удалить».
- При удалении папки — диалог: «Удалить вместе с дорожками?» с вариантами
  «Оставить дорожки» (по умолчанию, безопасный) и «Удалить дорожки».
- Порядок строк таймлайна: дорожки отрисовываются в порядке `tracks`; папка
  рисуется строкой над своими детьми, дети — с отступом и только когда папка
  развёрнута. Отступ визуальный, не меняет геометрию клипов (клипы по-прежнему
  по `track`-индексу строки).

### §5 Realtime safety

Папки не влияют на аудио-путь. Никаких изменений в `Graph::process`,
`Renderer::render`, `nodes::Mixer`, аудио-колбэке. Групповая громкость,
M/S и прочее для папок — **вне** этой задачи (отдельная спека).

## Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Пустой проект без папок | JSON без ключа `"folders"`, бит-в-бит как раньше |
| Создание папки из 0 дорожек | `EditorError` (не создаёт пустую папку неявно) |
| Дорожка уже в папке → собрать в папку ещё раз | ошибка, состояние не меняется |
| Папка в папке | запрещено (одноуровневая модель); понятная ошибка/недоступный пункт |
| Переместить папку | дети едут вместе, одна команда Undo |
| Свернуть папку → играть | звук детей не меняется |
| Удалить папку (по умолчанию) | дети остаются на верхнем уровне |
| Удалить папку + детей | дорожки удаляются, индексы других папок пересчитываются |
| Undo создания/удаления/переименования/сворачивания/перемещения/сборки | состояние восстанавливается полностью |
| Старый проект открывается | без изменений, папки пустые |
| Round-trip с папками | `to_json → from_json → to_json` идентичен |

## Вне области

- Групповая громкость, M/S, групповая автоматизация папки.
- Многоуровневая вложенность папок.
- Папка как шина (изменение маршрутизации детей).
