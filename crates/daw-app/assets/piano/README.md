# Сэмплы пианино

30 файлов MP3 (ноты A0, C8 и C, D#, F#, A в октавах 1–7) взяты из
**Salamander Grand Piano V3** — автор **Alexander Holm**, лицензия
[Creative Commons Attribution 3.0 (CC-BY 3.0)](https://creativecommons.org/licenses/by/3.0/).

Источник: <https://archive.org/details/SalamanderGrandPianoV3>, MP3-версия из
<https://github.com/Tonejs/audio/tree/master/salamander>.

Файлы не изменялись. Программа встраивает их в исполняемый файл
(`crates/daw-app/src/piano.rs`, SPEC-039).
